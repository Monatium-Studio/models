# 모나티엄 도시 키트 (monatium_city_kit)

교주 차원 모나티엄(엘리아스 동부의 엘프 도시)을 모듈로 조립하는 키트다. 인터루드 4~7 디오라마(`docs/art/interlude-elias.md`)와 1막 레벨(M1 개판 5분 전, M2 방어선, M3 둠스데이)과 1막 로딩 영상(위성 시점)이 같은 모듈과 같은 배치를 쓴다.

- 키트: `art/blender/lib/monatium_city_kit.py` (의존: `cb`, `home_weapons`)
- 소품: `art/blender/props/monatium_*.py` → `public/models/props/monatium_*.glb`
- 노드 규칙: `docs/LEVELS.md`. 이 문서 5장은 키트가 더하는 확장 노드다.

```bash
npm run model -- art/blender/levels/interlude_daily.py      # 키트를 쓰는 세트
npm run shot -- levels/interlude_daily.glb --views top,34
npm run model -- art/blender/props/monatium_barricade.py    # 소품
```

## 2. 시각 언어

**원작 배경 + 교주 차원 형태 언어.** 모나티엄 배경 일러스트의 밝은 현대 도시(크림 판석, 청색 유리, 콘크리트 고가, 녹음)를 바탕으로, 교주 차원 병기 문법(`weapons-home.md` 2장)을 건물에 옮긴다.

1. **둥근 판**: 건물 평면은 둥근 모서리 사각형(`rrect`), 시청 날개는 양 끝이 크게 둥글다. R41의 45° 모따기와 반대.
2. **스타디움 창**: 시청 창, 모노레일 차량 창 띠.
3. **금색 고리**: 가로등 밑동 고리, 시청 기둥머리, 탑 관, 분수 조형, 코어 AI 꼭대기 후광. 가는 금색 줄은 쓰지 않는다(R41 앰버 줄과 구분).
4. **시안 발광** `#7ff0ea`: 모나티엄 네트워크(코어 AI 띠, 바닥 네트워크 선, 모노레일 전력선, 감시 카메라 LED). HUD와 같은 색이다.
5. **남보라 + 청록**: 진압반 시설(훈련장 표지, 바리케이드, 현수막). 지휘 금색은 시청·현수막에만.
6. **엘프 로고 원판**: 남색 원판 + 금색 로고.

**체격**: 엘프 기준(키 1.2 m). 문 1.8 m × 1.0 m, 층고 2.7 m(1층 상가 3.2 m), 보도 3.2 m, 차로 2.8 m, 벤치 좌판 0.32 m, 가로등 3.6 m, 자판기 1.55 m, 연설대 단 위 0.64 m, 계단 단 높이 0.15 m(자동 오르기 0.28 m 안). 원경 고층만 층고 3.0 m.

## 3. 조립기 `City`

```python
C = mk.City("m2_streets")          # prop=True면 소품 모드 (그룹 없이 <이름>_<머티리얼>)
C.group("plaza")                   # 소문자 → zone_plaza 노드
C.group("STAGE_1", stage=1)        # 대문자 접두사 → STAGE_1 노드 (그룹 속성 = 노드 커스텀 속성)
C.box("concrete", x0, x1, y0, y1, z0, z1, col=True)   # 지오메트리 + COL_ 박스
C.npc("rita", (x, y, z), "characters/rita.glb", pose="look_up", face=(x2, y2), props={"scene": "invasion_a"})
C.cam("shot", [(t, cam_xyz, look_xyz, fov), ...])     # CAM_shot_01.. + LOOK_shot_01..
C.finish("levels/m2_streets.glb", root_props={...}, outline=0.025)
```
- 지오메트리는 (그룹, 머티리얼, 종류)별 bmesh에 쌓고 finish에서 메시 하나로 만든다. 그룹마다 머티리얼별 드로우콜 1개다.
- 종류 `kind`: `main`(루트 outline), `detail`(0.01 m), `far`(0.07 m, 원경), `fine`(아웃라인 없음: 데칼·글자·발광).
- 보이는 메시는 전부 `collider=0`. 충돌은 모듈이 함께 만드는 축 정렬 `COL_` 박스가 맡는다(원점 = 박스 중심, 회전 없음).
- 대문자 그룹(`STAGE_`, `RIFTS`, `ALERTS`, `MONORAIL_train`)에서 만든 마커는 그 노드의 자식이 된다. 그 그룹에서 만든 NPC 마커에는 `stage` 속성이 자동으로 붙는다.
- 프리미티브: `box rbox beam prism ring_prism cyl blob poly decal rect ring strip plate text logo`. 데칼 띄움은 기본 1.5 cm(원거리 깜빡임 방지).

## 8. 1막 레벨 재사용 메모

- **M1 개판 5분 전**: `downtown(variant="day")`에서 개전 당일 R41 병력·차량·드론이 밀려들고, 모나티엄 지하철 입구까지 밀려 후퇴한다. 인터루드 7과 같은 장소다. 후퇴선마다 `barricade`, `sandbag_wall`을 둔다. 지하철 역·터널 모듈은 아직 없다(4차 수정에서 생김).
- **M2 방어선**: 지하철 내 통로로 모나티엄 병기창고까지 간다(지하 통로·병기창고 실내 모듈 필요. 병기창고에는 노획 미군 화기가 있다. M1A1 등 구 기갑병기는 별도의 차고에 있다(2막 M6)). 이어 모노레일 선로 위를 따라 시청까지 후퇴하며 싸운다(모노레일 모듈 재사용, 선로 위 보행 충돌 필요). 시청 앞에 방어선을 쌓는다.
- **M2 시가전**: `downtown(training=False, skyline=True)` + 바리케이드·모래주머니 `PROP_` + 버려진 차량(vehicles 담당). 개전 컷은 `gate_r41("invasion", (0, 0, 38), radius=18, tilt=60)`을 광장 위에 둔다. 플레이 구역은 중앙로와 상가 줄, 광장. 상가 1층 진열창 뒤는 막혀 있으니(COL은 건물 전체 박스) 실내가 필요하면 별도 모듈로 판다. 흑뉴아가 키디언·리츠·칸나를 제압하는 원경은 코어 AI 탑 쪽(북동)에서 보이게 한다.
- **M3 마지막 프로토콜**: 시청(`city_hall`)과 코어 AI 탑. 카운트다운 동안 `LIGHT_alert_*`를 켜고, 끝나면 `core_ai(lit=False)` 상태로 바꾼다(띠 머티리얼을 `glow_off`로 교체하거나 STAGE식 겹침 노드).
- **M7 관측수**: `highway`의 고가 상판이 모나티엄-에르피엔 고속도로다. `x_end`를 늘리고 `gantry`를 여러 개 둔다.
- 충돌: 모듈마다 단순 `COL_` 박스를 이미 만든다. 인터루드 세트는 루트 `physics=0`이지만 같은 배치를 레벨로 내보내면 그대로 쓸 수 있다. 건물 블록은 통짜 박스라 지붕 위로 올라갈 수 있다(파라펫 높이 0.7 m).
- 예산: 플레이 레벨은 원경 고층(`skyline`)과 시청 뒤 건물을 줄이거나 원경 LOD로 바꿔 60k 안팎을 목표로 한다.

## 10. 1막 위성 브리핑 전경 `levels/act1_overview`

## 11. 1막 시청 방어선 시네마틱 세트 `levels/act1_cityhall`

로딩 영상 3 「종군기자 하이디」(하이디의 핸드헬드 카메라)와 1막 종료 「정전」의 지상 컷이 쓰는 보는 세트다(루트 `physics`=0). D-day 해 질 녘, 시청 계단 앞 방어선이 무너지는 순간이다. 인물·차량·드론은 마커만 두고 1막 연출 코드가 띄우고 움직인다. 지상 높이에서 보므로 키트 먹선을 그대로 쓴다(`outline` 0.025).

```bash
npm run model -- art/blender/levels/act1_cityhall.py
npm run shot -- levels/act1_cityhall.glb --views top,34     # 뷰어는 COL_ 상자도 그린다 (게임은 그리지 않음)
```

**[원작]** 시청 앞 광장, 진압반(고무탄 카빈), R41 드론과 차량의 돌입, 둠스데이 프로토콜의 인프라 파괴. **[오리지널]** 방어선 호의 모양과 자리, 쓰러지는 진압반원, 차량 돌입 경로(IFV가 방어선을 들이받음), 드론 배치, 구역별 정전 순서.

### 배치 (Blender m, 원점 = 광장 중심, +Y 북)
- `downtown(variant="dusk", training=False, train=True, highway_on=True, skyline=True, screens=True, train_x=-36)`. 가로등이 켜져 있다.

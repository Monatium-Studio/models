# R41 침공군 병력과 현장 지휘부

R41 모나티엄 제국군(흑뉴아의 침공군) 병사 모델 목록이다. 모두 **무명 오리지널 엘프**이고 원작 인물을 복제하지 않는다.
시각 언어는 `docs/art/r41-style.md`(PV 분석), 무기는 `docs/art/weapons-r41.md`, 키트는 `docs/art/ELF_KIT.md`를 따른다.

- 공용 모듈: `art/blender/lib/r41_troops.py` (`Trooper` = 엘프 키트 + R41 군복·장비)
- 병종 스크립트: `art/blender/enemies/*.py` → `public/models/enemies/*.glb`

```bash
npm run model -- art/blender/enemies/r41_rifleman.py            # a, b, c 모두 (-- b 처럼 하나만도 가능)
npm run shot -- enemies/r41_rifleman_a.glb
npm run shot -- enemies/r41_officer.glb --focus r41_officer_face --views front --morph shaken:1
R41_PREVIEW=1 npm run model -- art/blender/enemies/r41_riot.py  # 무기를 든 미리보기 r41_riot_preview.glb (커밋 안 함)
npm run shot -- enemies/r41_riot_preview.glb --anim pose
```

## 1. 공통 (PV 근거와 엘피니아 계보)

**PV 「여왕님의 마음으로 만든 나라」 3:00~3:03 클로즈업, 4:59~5:07 대열, 2:34~2:36 실루엣**에서 확인한 것을 모든 병종의 바탕으로 쓴다.

| 부위 | PV에서 본 것 | 모델 |
|---|---|---|
| 머리 | **밝은 회색 베레모**를 오른쪽 앞으로 눌러 씀, 짙은 머리띠에 골 줄. 헬멧이 아니다(사용자 정정) | `Trooper.beret()`: 머리띠 위에서 시작해 오른쪽(-X)이 처지는 크라운, 골 줄 두 개, 왼 눈 위 휘장 = 원작 엘프 로고 |

- **엘피니아 전투복 계보**: `_kit_elfinia_soldier`와 같은 셔츠·소매·바지·군화·벨트·견장 함수와 치수를 쓴다. 색만 PV 회색으로, 장비만 R41 것으로 바꿨다.
- **리타(교주 차원 특수작전부)와의 구분**: 리타 쪽은 자줏빛 회색 진압 장비와 남보라 지휘색, 둥근 진압 헬멧이다. R41은 **밝은 회색 전투복 + 베레모 + 연기색 고글 + 앰버 휘장**이다. 명도(밝음 대 중간), 머리 실루엣(납작하게 처진 베레모 대 둥근 헬멧), 강조색(앰버 대 금색·없음)이 모두 다르다.
- **엘프 로고**: ART_GUIDE 1장 예외. 베레모 휘장, 어깨 휘장, 가슴판, 망토, 방패, 등짐에 `r41.elf_logo_outline()`을 그대로 쓴 한 면 데칼이다(로고 하나 약 60~120 tris).
- **무기는 모델에 넣지 않는다.** `socket_hand_R`(주무기), `socket_hand_L`(방패), `socket_hip_R`(권총)에 붙인다. 허리의 G-5 수류탄과 권총집은 장식이다.

### 2.1 소총병 `r41_rifleman_a/b/c`
- [원작] R41 병사는 전원 실전 경험이 있는 군인 출신이다. 가장 많이 나오는 기본 적.
- 밝은 회색 베레모 + 앰버 원형 휘장, 연기색 고글, 헤드셋, 짙은 조끼 앞·뒤판(PV의 짙은 가슴), 탄입대 3개(제국 흑), 무전기, 등 파우치, 허리 G-5 하나.

### 2.2 진압반 `r41_riot` (+ `r41_riot_shield`)
- [원작] R41 진압반장은 타이다(R41)다. 진압반 표식은 **라벤더 회색 베레모(타이다(R41) 근무모 색) + 앰버 육각 휘장 + 양팔 앰버 띠 + 앰버 렌즈 고글**이다. 타이다(R41)의 의상·모자 모양은 쓰지 않았다.
- 제국 흑 판 조끼(가슴 앰버 엘프 로고, 금속 볼트, 막대 부호), 어깨·팔꿈치·무릎 보호대, 장갑, 오른 허벅지 권총집. 어깨 휘장이 원형이 아니라 육각이다.
- 방패: 세로로 긴 육각(0.45 × 0.61 m), 제국 흑 테 + 회백 면 + 앰버 가로 띠 + 시야창 + 엘프 로고 + 막대 부호, 뒷면 세로 손잡이·받침·팔 패드. 원점 = 왼손 파지점, 앞 = +Y, 위 = +Z(무기 소켓 규칙과 같다). 앵커 `grip`, `face`, `top`, `bottom`. 애니메이션에서는 왼손 엄지가 위를 보게 손목을 돌리면 방패가 선다.

### 2.3 돌격 편대 `r41_assault`
- [원작] 에르피엔 결전에서 중성자탄이 자기들을 향했다는 사실에 동요하고 죠안과 아멜리아(R41)의 설득으로 대거 이탈한 부대다. 투항 장면 때문에 **고글을 베레모 위로 올려 얼굴이 늘 보인다**(`shaken`, `scared` 표정).
- 표식: 짙은 회색 베레모 + 머리띠 앰버 아랫단 테 + 꺾쇠 휘장, 어깨에도 앰버 꺾쇠 휘장(막대 3).
- 중무장: 어깨·골반을 키운 체격, 제국 흑 판 조끼 + 본 화이트 가로 띠(R41 드론의 흑백 띠와 같은 언어), 큰 본 화이트 어깨 장갑과 무릎 보호대, 판 앞 G-5 셋, 탄약 파우치 둘, 탄약 등짐(본 화이트 띠, 앰버 로고, 안테나).

### 2.4 현장 지휘관 `r41_officer` (최종 목표)
- [오리지널] 흑뉴아가 에르피엔으로 떠난 뒤 모나티엄에 남은 현장 지휘관단. [원작] R41은 현장 지휘관에게 지휘권을 위임한 자율 임무 체계다.
- 아멜리아·포셔(R41)의 흰 코트를 군용으로 바꾼 본 화이트 롱코트(제국 흑 깃·소맷단·앞여밈·밑단, 앞트임과 뒤트임 자락), **제국 흑 망토(앰버 안감·밑단)**, 제국 흑 베레모(앰버 테, 이중 테 휘장).
- 견장 판에 앰버 줄 4개(현장 지휘관), 오른 어깨 앰버 장식 끈, 가슴 계급장(앰버 막대 셋), 대각 멜빵과 앰버 버클, 장갑(앰버 손목 테), 왼팔 휘장(본 화이트 테), 왼 손목 오각 화면 태블릿(`glow_dim` UNLIT), 오른 허리 권총집, 긴 군화.
- 키 1.24 m, 짙은 보라 장발, 진홍 눈. 기본 표정부터 눈을 살짝 내리깐 자신만만한 얼굴이다(`face(base=...)`).

### 2.5 지휘부 직속 경호대 `r41_hq_guard`
- 소총병 장비 위에 정예 표식: **본 화이트 베레모(흑 머리띠, 흑 테 휘장)**, 왼 어깨 본 화이트 망토(제국 흑 안감, 앰버 테, 등에 엘프 로고, 앰버 브로치), 제국 흑 판 조끼 + 본 화이트 앞판(흑 로고), L-11 탄창 파우치 셋, 오른팔 휘장(본 화이트 테), 무릎 보호대.

- 새 변형: `T.Trooper(name, variant=dict(eye=..., hair=..., style="bob|pony|short|long|bun", goggles="down|up"))`.

**머리카락 (헤어 v2, 2026-11-01)**
- 키트 v2 셸을 베레모 아래에 쓴다. 베레모가 정수리를 덮으므로 셸은 성글게(`cap(segs=16, rows=4)`) 하고, 머리띠 위는 키트 squash로 두피 쪽에 눌러 넣는다. 속층은 4 mm 더 안쪽으로 누른다(`_layered_squash`, 키트 squash가 두 층을 같은 거리로 눌러 머리띠 아래에 어두운 점이 비치던 문제).
- 앞머리 5다발이 머리띠 아래(고글을 내리면 고글 테)까지 오고, 옆머리는 귀 앞, 뒷머리 5다발은 목덜미에서 끝만 갈라진다. 셸 1.8~2.0k + 속층 260(지휘관 375).
- `pony`(소총병 b): 목덜미 위(뒤에서 -30°)에서 묶은 꼬리머리를 `cameo.Tail`(한 덩어리 볼륨 + 끝 다발 2개, 흔들림 본 `hair_tail_01..03`, 480 tris)로 만든다. PV 3:02의 밝은 갈색 꼬리.
- `long`(지휘관): `back(length=0.17)`이 키트 긴 머리 모드로 넘어가 흔들림 본 `hair_back_01..03`(chest 자식)이 생긴다.
- **헤드셋·고글 끈은 머리카락 위에 얹는다.** `Trooper.lift(az, el)`가 머리카락 셸(squash 뒤)을 광선으로 찾아 그 바깥 면 위 점을 준다. 귀마개는 귀 뿌리 바로 아래(az 92°, el -29°)의 옆머리 바깥 면 위, 머리띠는 귀 앞을 지나 베레모 머리띠 아래로, 붐 마이크는 귀마개 앞아래에서 입 쪽으로 간다. 고글 끈(내림)도 같은 방식으로 뒷머리 바깥을 감는다. 이전 판에서 옆머리에 가려지던 귀마개가 앞·옆·뒤 모두에서 보인다. `lift`는 처음 부를 때 머리카락을 완성하므로 `beret()` 뒤에 부른다.

## 4. 표정 (모프 타깃)

`blink`, `serious`, `surprised`, `pained`, `smile`(키트 기본) + **`alert`(경계), `angry`(분노), `shaken`(동요), `scared`(겁먹음)** (`r41_troops.EXPR`). 무표정은 기본 형태다.
- 모든 표정에 교정 키 `blink_<표정>`이 있다. **런타임 규칙: `blink_<표정> = blink × <표정>`**. ELF_KIT.md 6장 예시 코드는 표정 이름 네 개만 돌므로, R41 병사에는 `morphTargetDictionary`에서 `blink_`로 시작하는 키를 모두 찾아 같은 규칙을 적용한다.
- 투항 장면: `shaken` → `scared`. 돌격 편대와 고글을 올린 변형은 얼굴이 그대로 보이고, 고글을 쓴 병종은 반투명 렌즈 너머로 눈과 눈썹이 보인다.

## 6. 예산 메모

- 단역 설정 `segs=0.65, hand_q=0.6`(지휘관 0.8/0.7). 헤어 v2 셸이 v1보다 무거워 0.7에서 낮췄다. 소총병 14.3~14.7k, 병종 14.9~15.0k, 지휘관 15.7k.
- 비싼 순서: 머리카락(셸 1.8~2.0k + 속층 0.26k) > 얼굴(0.9k) > 베레모(0.63~0.94k, 휘장·테 포함) > 셔츠 > 군화. 판 조끼 한 벌(앞·뒤판 + 어깨끈 + 옆끈) 약 0.9k.
- 줄인 것: 조끼에 가려지는 셔츠 단추, 장갑 안의 맨손 손바닥, 머리띠 위 두피 덮개 분할, 보호대 끈(약 190 tris씩), 파우치 몰리 띠, 벨트 고리.
- 헤어 v2 재생성 때 더 줄인 것: 2.4 cm 이하 엘프 로고(베레모·어깨 휘장)의 외곽선 단순화(tol 0.010), 가슴·등짐 로고(tol 0.008), G-5 레버·붐 마이크 끝을 모서리 없는 상자로. 소총병 b는 무릎 보호대를 다는 대신 허벅지 파우치를 뺐다.

## 8. 남은 문제

- 헤드셋 머리띠가 귀 뿌리 앞을 지나므로 귀를 크게 움직이는 애니메이션에서는 귀와 겹칠 수 있다.
- 베레모 머리띠 아래 뒷머리 경계에 작은 어두운 점(가르마 홈·다발 경계)이 몇 개 남는다. 키트 squash 개선이 필요하다(characters-cameo.md 7장 키트 버그 보고).
- 코트 자락과 망토는 골반·허벅지 웨이트를 섞은 단단한 판이다. 크게 걷거나 앉으면 다리와 겹칠 수 있다(ELF_KIT.md 12장 한계).
- 미리보기 자세는 소켓 방향과 크기 확인용이다. 실제 사격·방패 자세는 애니메이션 작업에서 만든다.

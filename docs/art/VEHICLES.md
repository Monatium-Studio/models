# 차량 규약

차량 모델은 나중에 차량 게임플레이 시스템이 읽는다(운전 물리, 탑승, 포탑, 거치 무기). 그 시스템이 이름만 보고 동작하도록 아래 규약을 지킨다. 일반 규약은 ART_GUIDE.md, 무기 규약은 7장을 따른다.

## 좌표와 축척
- 1 BU = 1 m, **실물 크기**. 엘프(키 1.2 m)에게 인간 차량은 크다. 이 체격 차이가 볼거리다.
- **Blender에서 차량 정면은 -Y**(캐릭터와 같음 → three.js +Z). 원점은 차체 중심 아래 지면(z=0)이다.
- 결과물: `public/models/vehicles/<진영>/<id>.glb`. 진영은 `us`(노획 미군), `monatium`, `r41`.
- 스크립트: `art/blender/vehicles/<진영>/<id>.py`

## 노드 이름 (점 금지)
| 노드 | 종류 | 설명 |
|---|---|---|
| `body` | 메시 그룹 | 차체(움직이지 않는 부분). 머티리얼별로 join |
| `wheel_FL`, `wheel_FR`, `wheel_RL`, `wheel_RR` (6륜이면 `wheel_ML/MR`) | 메시 | 바퀴. 원점이 바퀴 중심이다. 커스텀 속성 `radius`(m), `steer`(1이면 조향 바퀴) |
| `track_L`, `track_R` | 메시 또는 빈 노드 | 궤도(전차). 커스텀 속성 `roadWheels`(보기륜 수). 보기륜은 `roadwheel_L_01..`처럼 분리한다(회전용). 궤도가 돌게 하려면 슈를 `track_L_s00..`(경로 순서, 원점 = 경로 위 슈 가운데, 모두 같은 모양으로 한 피치 간격) 자식 노드로 나눈다: 게임이 달린 거리만큼 각 슈를 다음 슈 자리 쪽으로 옮기고 돌린다(`Vehicle.updateTracks`, 바닥 슈는 땅에 대해 선다) |
| `turret` | 빈 오브젝트 또는 메시 | 포탑 요(좌우) 회전축. 원점이 회전 중심이다 |
| `gun_pitch` | 빈 오브젝트(turret의 자식) | 포신 피치(상하) 회전축. 커스텀 속성 `pitchMin`, `pitchMax`(도) |
| `mount_<id>` | 빈 오브젝트 | 거치 무기 회전축(예: `mount_m2` 링 마운트, `mount_coax`). 커스텀 속성 `weapon`(무기 정의 id), `yawMin/yawMax`, `pitchMin/pitchMax` |
| `muzzle_<id>` | 빈 오브젝트 | 총구·포구. 거치 무기의 자식 |
| `eject_<id>` | 빈 오브젝트 | 탄피 배출구 |
| `seat_<role>` | 빈 오브젝트 | 탑승 자리(`driver`, `gunner`, `commander`, `passenger_1` 등). 1인칭 시점 위치(엘프 눈높이)에 두고 -Y가 정면이다 |
| `enter_<role>` | 빈 오브젝트 | 지면의 탑승·하차 위치 |
| `crew_<role>` | 빈 오브젝트 | 선택. AI 승무원이 해치로 몸을 내미는 자리(`commander`, `driver`): 해치 구멍 가운데, 해치 테 윗면 높이, -Y가 정면. 포탑 해치는 `turret`의 자식. 0.9 m 안의 `hatch_*`가 그 해치다(승무원이 나와 있으면 열림). 구멍 반지름 0.27 m 이상, 아래는 어두운 우물 (docs/COMBAT.md 12.3) |
| `door_<id>`, `hatch_<id>` | 메시 | 열리는 문·해치. 커스텀 속성 `rotAxis`, `rotDeg` 또는 `move`. 사람이 지나가는 문 뒤에는 차체에 실제 출입구를 뚫는다 (탑승 연출이 카메라로 지나간다. 닫으면 문판이 덮게 3~4 cm 안쪽) |
| `light_head_L/R`, `light_tail_L/R` | 메시 | 전조등·후미등(UNLIT, 켜고 끄기용) |
| `exhaust_<n>` | 빈 오브젝트 | 배기·추진 이펙트 위치 |
| `COL_hull` 등 | 메시 | 충돌 전용 단순 볼록 형상(박스나 볼록 껍질 몇 개). 렌더하지 않는다. 로켓·포탄은 이 껍질에 닿아도 터진다(열린 차체 틈으로 빠져나가지 않게) |
| `wreck_debris_<n>` (또는 `debris_<n>`, 커스텀 속성 `wreck: "detach"`) | 메시 | 선택. 격파될 때 떨어져 날아가는 판·바구니·예비 바퀴 등. 없으면 그을린 판을 만들어 날린다 |
| `wreck_fire_<n>` | 빈 오브젝트 | 선택. 격파 뒤 불이 타는 자리 (최대 4). 없으면 배기구·엔진 갑판, 차체 위 가운데, 해치 |
| `wreck_smoke` | 빈 오브젝트 | 선택. 손상·격파 연기 기둥이 오르는 자리. 없으면 배기구(`exhaust_*`) 평균, 없으면 차체 뒤쪽 위 |

## 루트 커스텀 속성
- `vehicleClass`: `wheeled` / `tracked` / `hover`
- `mass`(kg), `maxSpeed`(m/s), `wheelbase`, `track`(윤거)
- `armor`: `light` / `medium` / `heavy`. 무기 등급·맞은 면과 함께 차체 피해를 정한다 (docs/COMBAT.md 9장). 주말농장 법칙은 사람만 지킨다: 차량은 무력화(엔진 정지·포탑 고장, 잠깐)와 격파(내구도 0, 잔해)가 있다.
- `hp`: 선택. 차체 내구도 (기본 100). 차량 정의 `durability`보다 우선한다.
- `outline`: 차량은 0.008~0.012

## 격파 (잔해)
게임이 모델을 그대로 잔해로 바꾼다. 따로 잔해 모델을 만들지 않는다.
- 머티리얼을 차량마다 복제해 그을린 색으로 바꾸고, 불씨 빛(발광)을 몇 초 동안 식힌다. 아웃라인 헐·`COL_`은 건드리지 않는다.
- `turret`은 튀어 올랐다가 기울어 내려앉고(회전 중심이 원점이어야 자연스럽다), `gun_pitch`는 아래로 처진다. `mount_*`(포탑에 달리지 않은 것)는 최저 피치로 처진다.
- `hatch_*`는 활짝, `door_*`는 반쯤 열린다 (`rotAxis`·`rotDeg` 등 문 규약 그대로).
- 충돌 메시는 그대로 남아 정적 엄폐물이 된다.

## 무기 연동
- 거치 무기(M2 중기관총, 공축 기관총, 주포 등)는 **무기 시스템의 데이터 정의를 그대로 쓴다**. 무기 모델은 별도 glb(`weapons/...`)로 만들고, 차량의 `mount_<id>`에 붙인다.
- 예: M2는 `weapons/us/m2.glb`(거치형, 손잡이와 장전 손잡이 포함), 전차 주포는 차량 메시의 일부이고 `muzzle_main`만 둔다.
- 주포 주퇴복좌: 포방패와 포신이 `gun_pitch` 아래 한 메시여도 된다. 차량 정의 `recoil.barrelFrom`(gun_pitch 로컬에서 포구 쪽으로 m)보다 앞의 삼각형을 런타임이 `gun_recoil` 묶음으로 떼어 뒤로 민다(`vehicles/gunKick.ts`, M1A1 0.7 m: 포방패 0.31~0.67 m는 남는다). 포신 관은 포방패 안쪽까지 이어 두지 않아도 된다(뒤로 들어가며 가려진다). `muzzle_main`은 `gun_pitch`에 둔다(쏘는 순간의 포구).
- 거치 무기 glb도 무기 규약(원점 = 회전축 또는 파지점, 총구 +Y, `muzzle`, `eject`, 움직이는 파츠)을 지킨다.

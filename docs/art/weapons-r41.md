# R41 노획 병기 · 드론 목록

R41 모나티엄 제국군의 무기 5종과 드론 3종. 시각 규칙은 `docs/art/r41-style.md`, 공용 헬퍼는 `art/blender/lib/r41.py`.
근거는 테마극장 「여왕님의 마음으로 만든 나라」 PV(YouTube `7q68zvW9ZCo`) 3:00~3:03의 R41 소총이다. 모든 무기는 **실탄 화기**다.
수치는 **Blender 좌표**(Z-up, m)다. three.js에서는 `(x, y, z)_three = (x, z, -y)_blender`.

```bash
npm run model -- art/blender/weapons/r41/r41_carbine.py
npm run shot -- weapons/r41/r41_carbine.glb --views side,34,top,muzzle --focus r41_carbine
npm run shot -- weapons/r41/r41_carbine.glb --mode fp            # fpOffset, fpRot 자동 적용
npm run shot -- weapons/r41/r41_carbine.glb --mode fp --ads 1    # 정조준: sight_eye가 카메라에
npm run shot -- drones/drone_gunship.glb                         # front,34,side,back
npm run shot -- drones/drone_gunship.glb --views top,34,low,34b --out shots/drones__drone_gunship-top.png
```

## 공통 규약
- **무기**: 원점 = 오른손 파지점(손잡이 중앙), 총구 +Y, 사수 오른쪽 +X. 1인칭 카메라는 총의 **왼쪽 면(-X)**을 보므로 엘프 로고, 조정간, 노획 태그를 왼쪽에 둔다. 배출구는 오른쪽이다.
- **드론**: 정면 -Y(캐릭터와 같음), 가장 낮은 점 z=0, 기체 왼쪽 = +X (`_L`).
- **노드 이름**: 정지 파츠는 머티리얼별로 `<루트>_<머티리얼>`, 데칼(엘프 로고, 막대 부호)은 `<루트>_decals`(`noOutline=1`). 움직이는 파츠는 아래 표의 이름이고, 원점이 회전축이나 이동 기준점이다.
- **도장**: 회백(`light`) 몸통 + 앰버 띠·줄 + 어두운(`shell`) 탄창·손잡이·개머리. 총기의 발광은 야간 조준점(`glow_amber`)과 조준경 레티클(`glow`)뿐이다.
- 예산: 1인칭 무기 12k 삼각형 · 머티리얼 8개, 드론 5k · 6개 (ART_GUIDE 8장).

### K-7 '쐐기벌' (`r41_carbine`)
- PV 근거(3:00~3:03): 회백 리시버·핸드가드, 이음매의 앰버 띠, 가는 앰버 줄, 슬롯 소염기, 핸드가드 앞 위의 높은 가늠쇠, 핸드가드 옆 가로 슬롯, 아래 모듈(앰버 줄), 삼각 트러스 무늬 삽입구, 어두운 곡형 탄창(가로 골), 어두운 손잡이와 접이식 개머리.
- 추가 디테일: 위 레일 리브, 고리형 가늠자(구멍 지름 8.8 mm), 가늠쇠 앰버 야간 점, 왼쪽 조정간(앰버 끝)과 노리쇠 멈치, 오른쪽 배출구·탄피 걸림쇠·탄창 멈치, 버퍼 튜브의 앰버 고리, 엘프 로고(리시버 왼쪽 `shell`, 개머리 양쪽 `amber`), 노획 태그.
- 움직이는 파츠
  - `mag` (0, 0.093, 0.030): 아래로 뽑는다
  - `bolt` (0.0158, 0.026, 0.078): 배출구 안, 쏠 때 -Y로 왕복한다
  - `charging_handle` (0, -0.050, 0.088): AR식 T자, -Y로 당긴다
  - `trigger` (0, 0.040, 0.028): X축 회전
- 앵커: `muzzle` (0, 0.327, 0.074) · `grip_support` (0, 0.200, 0.030) · `sight_eye` (0, -0.130, 0.122) · `eject` (0.019, 0.026, 0.078) · `mag_well` (0, 0.093, 0.030)

### P-2 '등에' (`r41_sidearm`)
- 회백 슬라이드(앞뒤 홈, 위 짙은 리브, 앰버 줄), 어두운 프레임(앰버 줄, 더스트 커버 레일, 비버테일), 손가락 홈 3개, 큰 방아쇠울, 3점 앰버 야간 조준기, 회백 탄창 바닥판(앰버 줄), 프레임 왼쪽 앰버 엘프 로고, 끈 고리와 노획 태그.
- 움직이는 파츠: `slide` (0, -0.040, 0.064) -Y로 후퇴 · `mag` (0, -0.004, 0.018) 손잡이 축(-14°)을 따라 아래로 · `trigger` (0, 0.036, 0.026)
- 앵커: `muzzle` (0, 0.110, 0.064) · `grip_support` (-0.014, 0.004, -0.014) · `sight_eye` (0, -0.150, 0.085) · `eject` (0.013, 0.032, 0.066) · `mag_well` (0, -0.004, 0.018)

### S-3 '말벌집' (`r41_suppressor`)
- 육각 회전 약실(제국 흑, 면마다 육각 창 2개로 앰버 탄피가 보임 = 벌집), 회백 리시버·요크·열 차폐(통풍 구멍, 앰버 줄), 어두운 펌프(금속 리브), 육각 총구 머리(앰버 띠, 돌파용 톱니 4개), 고리형 가늠자와 앰버 점 가늠쇠, 짧은 어깨 받침. 엘프 로고는 리시버 왼쪽(`shell`)과 받침 뒷면(`amber`, 1인칭에서 보임).
- 움직이는 파츠: `cylinder` (0, 0.056, 0.064) **Y축 회전**, 한 발에 60° · `pump` (0, 0.162, 0.056) -Y로 약 0.04 m · `trigger` (0, 0.050, 0.030)
- 앵커: `muzzle` (0, 0.270, 0.086) · `grip_support` (0, 0.162, 0.040) 펌프 아래 · `sight_eye` (0, -0.120, 0.127) · `eject` = `mag_well` (0.026, 0.002, 0.064) 오른쪽 장전 게이트(탄피를 빼고 넣는 곳)

### L-11 '잠자리' (`r41_dmr`)
- 회백 리시버(앰버 줄, 위 레일), 어두운 골격 개머리(오각 구멍) + 회백 뺨받침, 팔각 회백 핸드가드(앞뒤 앰버 띠, 통풍 구멍), 핸드가드 아래 접힌 양각대(잠자리 다리, 앰버 발), 홈 파인 총열 + 앰버 총열 너트, 측면 포트 소염기, 조준경(육각 대물렌즈 + 앰버 띠, 위에 벌집 킬플래시 7칸 = 겹눈, 바이올렛 렌즈, 뒤 화면의 마젠타 조명 레티클), 10발 직선 탄창(앰버 바닥 줄), 리시버 왼쪽 엘프 로고.
- 움직이는 파츠
  - `mag` (0, 0.128, 0.030): 아래로 뽑는다
  - `bolt` (0.0182, 0.050, 0.075): 배출구 안, -Y로 왕복한다
  - `charging_handle` (0.0195, -0.030, 0.095): 오른쪽 노리쇠 손잡이(앰버), -Y로 당긴다
  - `trigger` (0, 0.050, 0.026)
- 앵커: `muzzle` (0, 0.458, 0.075) · `grip_support` (0, 0.232, 0.050) · `sight_eye` (0, -0.120, 0.131) · `eject` (0.021, 0.050, 0.075) · `mag_well` (0, 0.128, 0.030)

### G-5 '땅벌' (`r41_grenade`)
- 어두운 육각 캔 위아래에 벌집형 파편 돌기 40개, 가운데 회백 띠(앰버 줄), 아래 앰버 고리, +X 면 앰버 엘프 로고, 앰버 레버(-X 면), 강철 안전핀 고리에 노획 태그.
- 원점 = 쥐는 손 중심(몸통 중심), 위 = +Z. `fpRot 0,-115,0`으로 1인칭에서 로고 면이 카메라를 향한다.
- 움직이는 파츠: `lever` (0, 0, 0.059) 신관 위 경첩 · `pin` (0, -0.002, 0.0505) -Y로 뽑는다(노획 태그가 함께 빠진다)
- 앵커: `fuse` (0, 0, 0.062) · `core` (0, 0, -0.010) 폭발 이펙트 중심 · `grip_support` (-0.024, 0, 0.020)

### D-1 '모기' (`drone_swarm`)
- 말벌 허리 동체(본 화이트 등판 + 배 띠), 아래를 향한 오각 센서판 위 마젠타 고리-점 눈, 동체 양옆 엘프 로고, 턱 아래 기관총 포드(총열 + 소염기 + 앰버 고리 + 기관부 + 탄통), 육각 덕트 4개(세라믹 테, 바깥 항법등), 배 아래 짧은 스키드, 꼬리 안테나.
- 회전부: `rotor_FL` (0.118, -0.072, 0.049) · `rotor_FR` (-0.118, -0.072, 0.049) · `rotor_BL` (0.118, 0.078, 0.049) · `rotor_BR` (-0.118, 0.078, 0.049). 각자 원점에서 Z축으로 돈다. FL·BR과 FR·BL은 서로 반대 방향이다.
- 앵커: `eye` (0, -0.097, 0.033) · `muzzle` (0, -0.113, 0.008) 포드 총구 · `center` (0, 0, 0.037)

### D-9 '장수말벌' (`drone_gunship`)
- 로프트 동체(머리 · 잘록한 목 · 가슴 · **말벌 허리** · 배), 가슴 본 화이트 등판, 배 흑백 띠 3줄, 오각 얼굴판에 눈 셋, 큰턱 충돌 가드 한 쌍(앰버 띠), 가슴 위 뿔 지느러미 한 쌍(앞전 발광, 바깥 면 엘프 로고), 육각 덕트(아래 마젠타 양력 띠, 바깥 면 엘프 로고), 턱 포탑의 쌍열 기관총(구멍 뚫린 덮개 + 앰버 띠 + 소염기) + 포탑 왼쪽 탄통과 급탄 슈트, 꼬리 팔각 노즐(앰버 테), 착지 스키드.

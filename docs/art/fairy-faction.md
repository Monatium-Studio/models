# 요정 진영: 폴랑, 요정 경비대, 에르핀, 경비대 머스킷

요정 왕국 에르피엔 쪽 인물과 무기의 기록이다. 원작 식별 요소, 재해석한 부분, 근거 자료, 삼각형 수를 적는다.
원칙은 ART_GUIDE 1장을 따른다. 원작 팬이 한눈에 알아보도록 머리색, 헤어스타일, 눈, 상징 소품, 색 배합은 유지하고,
형태는 3D SD로 다시 그린다. 원작 이미지는 저장소 밖 스크래치패드에서만 봤다.

- 공용 헬퍼: `art/blender/lib/fairy.py` (키트 `elf.py` 위의 요정 특징 + cameo2 헬퍼 복사본)
- 인물: `art/blender/characters/{polan, fairy_guard_common, fairy_guard, fairy_guard_b, fairy_guard_officer, erpin, erpin_royal}.py`
- 무기: `art/blender/weapons/fairy/fairy_guard_musket.py`
- 결과물: `public/models/characters/{polan, fairy_guard, fairy_guard_b, fairy_guard_officer, erpin, erpin_royal}.glb`, `public/models/weapons/fairy/fairy_guard_musket.glb`

## 3. 폴랑 (`polan.glb`)

원작: 에르피엔 경비대장. 이 작품에서는 침공전의 에르피엔 방어 지휘관, 에필로그 대관식에서 에르핀의 마차 곁을 지키는 경비대장(원작 대관식 컷에 머스킷을 든 폴랑이 마차 옆에 있다).

| 요소 | 원작 | 3D |
|---|---|---|
| 머리 | 흰 긴 생머리, 한쪽 눈을 덮는 앞머리 | `#eeecf3`(그림자 라벤더 회색). 옆머리는 가슴 앞, 뒷머리는 허리. **왼눈(+X)을 덮는 큰 다발**과 챙 아래로 뾰족하게 내려오는 앞머리 다발 둘. 덮는 쪽은 PV 2:41~2:43과 사도 소개 이미지 기준(카드 일러스트는 좌우가 뒤집혀 있다) |
| 눈 | 청록 눈 속 흰 별 반짝임, 날카로운 눈매, 눈 밑 점 | 홍채 `#57b4a3`, `star="sparkle"`, 오른눈(-X) 바깥 아래 점, 굵은 짙은 눈썹 |
| 샤코 | 초록, 검은 띠·챙, 금 구슬 끈, 금 쐐기, 금 나비, 왼쪽 큰 금색 깃털 | 같은 구성. 깃털은 다섯 가닥 금색 다발 |
| 복장 | 흰 튜닉(세운 깃, 금 토글), 초록 연미복, 오른 어깨 초록 망토와 뺨까지 솟은 깃, 금 견장·장식끈, 흰 바지, 검은 롱부츠(금 나비) | 같은 구성. 연미복 금 테두리, 소맷단 금줄 1, 망토 자락에 나비 문장 |

## 5. 에르핀 (`erpin.glb`, `erpin_royal.glb`)

> 사용자 정정: **기본 에르핀(엘다인 각성 이전)과 에르핀(왕도)는 별개의 판**이다. 식별 요소를 섞지 않는다. '대관식 예복'은 왕도판에만 쓴다.

| | `erpin.glb` (엘다인 각성 이전 기본 에르핀) | `erpin_royal.glb` (에르핀(왕도), 대관식) |
|---|---|---|
| 근거 | 카드 2장, 사도 소개(일본판), 피규어 | 왕도 카드·소개, 사복 '왕관의 주인공'(대관식 복장), 대관식 GIF·퍼레이드 컷 |
| 머리 | 발목까지 오는 꿀빛 금발 생머리, +X 쪽 옆 땋은 머리, +X 크리스털 머리핀 | 금발 올림머리, 끝이 분홍으로 물드는 양 갈래 땋은 머리, 바보털, 프릴 보닛(딸기·흰 꽃) |
| 눈 | 붉은 주황(위쪽 짙은 자주), **노란 별 동공**, 덧니 | 붉은 분홍에 흰 반짝임, 덧니, 기본 입 'ω' |
| 왕관 | 크리스털 금 티아라 '애도하는 희망의 왕관' → 별도 노드 `erpin_crown` | 색을 되찾은 '축복의 왕관'(금관, 붉은 보석, 진주) → 별도 노드 `erpin_royal_crown` |
| 날개 | 작은 흰·분홍 깃털 날개 (`wings()`) | 큰 흰 깃털 날개 + 분홍 반투명·발광 막 날개와 흰 맥 (`erpin_royal_wing_membrane`, noOutline) |
| 복장 | 붉은 후드 칼라 케이프, 땅까지 오는 붉은 망토(흰 털 방울 밑단), 금테 흰 원피스(가슴 크리스털, 검은 허리끈, 금테 앞판), 검은 가터, 레이스 니삭스, 금띠 흰 부츠 | 흰 2단 프릴 드레스(진주 테두리, 분홍 속치마), 붉은 줄무늬 어깨띠와 흰 꽃 훈장, 가슴 리본, 어민 테두리 붉은 대관식 망토, 흰 장갑, 흰 양말, 붉은 구두 |
| 표정 | 키트 5종 + `grin`(덧니 웃음) + `teary`(울먹) + `pout`(뾰로통) | 키트 5종 + `regal`(위엄 있는 미소) + `moved`(감격) + `cheer`(퍼레이드 환호) |
| 장면 | 침공전 전반부 | 에필로그 3차 대관식 |

- 겹치는 요소는 금발, 요정 날개, 붉은 계열뿐이다. 기본판의 크리스털 티아라·붉은 후드 케이프·풀어 내린 긴 머리 + 한쪽 땋기·별 동공은 왕도판에 쓰지 않았다.
- **왕관 사용 규칙**: 원작에서 왕관은 시즌 2 챕터 8에서 힘을 잃었고 시즌 3부터 에르핀은 왕관 없이 나온다. 침공전 종전 뒤 다시 수여된다. 그래서 침공전 장면의 `erpin.glb`는 `erpin_crown`을 숨기는 쪽을 권한다. `erpin_royal_crown`은 대관 순간에 켠다.
- 두 판 모두 귀는 머리카락에 가려 만들지 않았다(`ears=None`). 홀(지팡이)은 넣지 않는다(`socket_hand_R`).
- 인물 전용 헬퍼는 `art/blender/characters/erpin_common.py`(덧니·별 동공 위치를 고친 `ErpinFace`, 숨길 수 있는 소품 노드 `node_part`, 털 방울·어민·프릴·진주를 한 메시로 만드는 `bead_tube`, `gem`, `flower`, `shell_panel`).

## 6. 요정 경비대 머스킷 (`weapons/fairy/fairy_guard_musket.glb`)

**이름과 형태 판정.** 사용자는 '머스킷'이라고 부른다. `docs/art/r41-style.md`(1장 표, 6장)는 PV 2:40~2:55의 총을 '볼트액션 소총'으로 적었지만, 프레임을 다시 보면 **전장식 플린트록 머스킷**이다.
- PV 2:43(총구 쪽 근접), 경비대 GIF, 폴랑 카드: 총열 아래 **꽂을대**가 검은 관 두 줄로 보인다. 금색 총열 띠, 손목 위 금색 공이 곡선, 옆으로 고리 결합한 소켓 총검.
- PV 2:52~2:56(일제 사격 옆모습): 볼트 손잡이가 없다.
- 나무위키 「요정」: 폴랑이 '코코'를 역설계해 "머스킷을 양산". 사용자 표현, PV 외형, 원작 설정이 모두 일치한다. → r41-style.md의 '볼트액션' 표기는 고칠 후보(그 문서 담당에게 넘긴다).

## 8. 키트에 올릴 후보와 남은 문제

| 후보 | 내용 |
|---|---|
| `Elf(ears="round")` | 사람 귀. 요정·사람 계열 인물 공용 |
| `e.wings()` | 볼록 쿠션 조각을 겹친 데포르메 날개 + 날개 본. 조각 경계 아웃라인이 원작의 깃 선 역할 |
| `Face(star=, eyes=False)` | 눈 속 별(반짝임·별 동공)과 눈 가린 단역 얼굴 |
| `pillow()` | 볼록 2D 외곽선 → 가장자리 얇은 쿠션. 날개, 리본, 장식판에 두루 |
| 모자 일반화 | `shako()`의 '머리 표면을 따르는 아래 고리 + 윗면 평면 + 챙 + 머리카락 눌러 넣기'를 정모·베레모와 묶어 `e.hat()`으로 |
| `taper_strip()` | 폭이 변하는 띠 한 덩어리(조각 띠를 이으면 아웃라인이 들쭉날쭉해진다) |

| erpin_common 헬퍼 | `ErpinFace`(덧니 `fang=`, 별 동공 위치), `node_part`(숨길 수 있는 소품 노드), `bead_tube`(털 방울·어민·프릴·진주 띠) |

- `membrane_wing()`은 처음에 반투명 막을 body 메시에 합쳐 아웃라인 헐이 생겼다. 지금은 별도 노드 + noOutline으로 남긴다(에르핀(왕도)는 같은 처리를 erpin_common에서 따로 했다).
- 에르핀 기본판 케이프 칼라가 어깨에서 조금 납작해 보이고, 왕도판 퍼프 소매가 각지며 바보털이 왕관 앞을 지난다. 두 모델 모두 삼각형 여유가 적다(머리카락 4.2~4.4k).
- 비볼록 2D 외곽선을 중심에서 방사형으로 채우면 면이 접힌다(첫 날개 시안의 문제). 쿠션은 볼록 조각으로만 만든다.
- 샤코 금 쐐기의 넓은 끝이 가까이서 조금 각져 보인다.
- 견장은 SD 머리에 가려 정면에서 잘 보이지 않는다(어깨가 머리 아래에 있다).
- 경비대 연미복 뒤 트임 사이로 흰 튜닉이 1 cm 정도 보인다(의도: 꼬리 갈라짐).
- 폴랑의 세운 깃은 SD 머리의 볼과 겹쳐 원작처럼 뺨까지 올리지 못하고 턱선까지만 올렸다.

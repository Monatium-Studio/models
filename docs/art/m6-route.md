# 구 기갑병기 보관고 키트 (monatium_depot_kit) · M6 전차 경로 레벨

2막 M6 후반: 수용소 북문 → 모나티엄 구 기갑병기 보관고(차고, 병기창고와 별개) → 공장 지대 길 → 모노레일 교차로 → 도심 입구 → 시청 앞. 새벽.

- 키트: `art/blender/lib/monatium_depot_kit.py` (도시 키트·폐허 키트 위)
- 레벨: `art/blender/levels/m6_route.py` → `public/models/levels/m6_route.glb` (약 41.5k tris, COL 135, 마커 78)

## 1. 근거
- [오리지널, 2026-11-01 사용자 확정] 구 기갑병기는 병기창고가 아니라 별도의 차고에 모여 있다. 노획 미군 전차 M1A1(`vehicles/us/m1a1.glb`, 관리번호 `MNT-T01`)은 인간 물건이라 정전 영향이 적다.
- [오리지널, 이번 작업에서 정함] R41 차량은 승무원이 손으로 다시 깨운다(수동 크랭크·점프 시동). 경로에 `state=off`로 둔다.

## 2. 모듈
| 함수 | 내용 |
|---|---|
| `garage(C, x0,x1,y0,y1, door_c=)` | 보관고: 벽마다 COL, 동쪽 큰 셔터 `DOOR_garage`(위로 5.6 m), 남쪽 사람 문(항상 열림), 지붕, 간판 「구 기갑병기 보관고 · OLD ARMOR DEPOT」, 선반·상자·작업대·체인 호이스트 |
| `tarp_over(C, name, …)` | 차량에 덮은 올리브 방수포 (이름 있는 메시, 미션이 걷어 낸다): `TARP_m1a1`, `TARP_humvee` |
| `warehouse`, `industrial_road`, `jersey`, `hull_down` | 길가 창고(셔터), 차선 있는 도로, 콘크리트 방호벽(엄폐 0.84 m), 장갑차 은폐호 |

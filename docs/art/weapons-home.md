# 교주 차원 제식 병기 (weapons/elfinia, weapons/monatium)

리타의 무장 3단계 중 첫 단계(`docs/scenario.md` 1장 '장비'). 프롤로그(지구 침공 당일 훈련 시뮬레이션)는 **엘피니아 군 제식 화기**, 1막 초반은 **모나티엄 진압반 제식 장비**를 쓴다. 이후 노획 미군 물자(`weapons-us.md`), R41 노획 병기(`weapons-r41.md`)로 넘어간다.

- 스크립트: `art/blender/weapons/{elfinia,monatium}/*.py`
- 공용 헬퍼: `art/blender/lib/home_weapons.py` (팔레트, 둥근 판·관·스윕, 데칼·글자, 엘프 로고, `Gun` 조립기)
- 결과물: `public/models/weapons/{elfinia,monatium}/*.glb`

```bash
npm run model -- art/blender/weapons/monatium/monatium_riot_carbine.py
npm run shot -- weapons/monatium/monatium_riot_carbine.glb --views side,34,top,muzzle --focus monatium_riot_carbine
npm run shot -- weapons/monatium/monatium_riot_carbine.glb --mode fp           # fpOffset, fpRot 자동 적용
npm run shot -- weapons/monatium/monatium_riot_carbine.glb --mode fp --ads 1   # 정조준
```
뷰어의 `left` 뷰는 무기의 **오른쪽 면(+X)**, `right` 뷰가 1인칭에서 보이는 **왼쪽 면(-X)**이다(캐릭터 기준 이름).

## 2. 형태 언어와 R41 대비

### 2.1 교주 차원 화기 문법 (두 진영 공통 = 계보)
1. **둥근 판.** 옆모습 돌출 + 3단 베벨, 둥근 사각 단면 교집합(`hw.sculpt`). R41의 45° 모따기와 반대.
2. **스타디움 창과 둥근 구멍 줄.** 총열 덮개·슬라이드 앞의 긴 원형 창, 개머리·슬라이드 뒤의 구멍 3~4개 줄.
3. **금색 총구 고리.** 모든 총기의 총구 끝(발사기는 앞으로 벌어진 나팔), 전기충격봉은 날밑, 수류탄은 신관.
4. **손 전체를 감싸는 D자 고리.** 소총·카빈은 손잡이 밑에서 앞으로 나와 몸통에 붙는 큰 고리(4손가락 장갑 손), 발사기 펌프는 칸나식 사각 고리 손잡이.
5. **짧은 개머리.** 엘프 팔 길이에 맞춰 방아쇠~개머리 끝 0.23 m 안팎(불펍).
6. **시안 발광.** 조준점·잔탄 표시창·충전 칸. 잔탄 표시창은 모나티엄 네트워크(HUD)와 연동되는 설정.
7. **엘프 로고 원판.** 왼쪽 면(1인칭에서 보이는 면)이나 권총 손잡이에 원판 + 금테 + 금색 원작 엘프 로고.

### 2.2 엘피니아(정규군) → 모나티엄(진압반)
| | 엘피니아 군 (지구 침공, 정규군) | 모나티엄 진압반 (엘리아스, 경찰·진압) |
|---|---|---|
| 외장 | 회녹 폴리머 `olive` (전투복 계열) + 자줏빛 건메탈 | 남보라 `violet` (진압반 지휘색) + 자줏빛 건메탈 |
| 로고 원판 | 엘피니아 남색 `navy` (계급장 바탕) | 짙은 남보라 `violet_d` |
| 탄 | 화약식 실탄 (놋쇠 탄이 탄창 창으로 보임) | 고무탄·고무 충격탄 (**청록 비살상 띠**, 청록 탄두가 창으로 보임) |
| 조준 | 광점 조준기(시안 레티클), 노출 공이치기 | 값싼 고리 가늠자, 격침식, 손전등, 앞 손잡이 |
| 명칭 | `7식`, `5식` + 공구 이름 (엘프 로고 = 톱니바퀴 + 렌치) | `MR-` (Monatium Riot) + 재우고 혼내는 이름 |

### 2.3 R41과의 구분 (`r41-style.md` 6장 대비표를 따름)
| 항목 | 교주 차원 (이 문서) | R41 |
|---|---|---|
| 몸통 색 | 어두운 자줏빛 회색 · 회녹 · 남보라 | 회백 `#cbc8d1` |
| 강조색 | 금색 `#d6b25e`, 청록 `#3f9a94` (비살상), 경고 노랑 `#e8c34a` | 앰버 `#f09a3e` 띠·가는 줄 |
| 발광 | 시안 `#7ff0ea` | 마젠타 `#ff4fd8`, 앰버 야간 점 |
| 모서리 | 둥근 베벨, 스타디움 창, 둥근 구멍 | 45° 모따기, 육각·오각 부품 |

## 4. 공통 규약

| 항목 | 내용 |
|---|---|
| 원점 | 오른손 파지점(손잡이 중심). 수류탄은 몸통 중심, 전기충격봉은 손잡이 중심 |
| 축 (Blender) | 총구 +Y, 위 +Z, 사수 오른쪽 +X. three.js에서는 총구 -Z |
| 노드 | 루트 empty(무기 이름) > `body`(정지 파츠, 머티리얼별 프리미티브) + `body_fine`(데칼·글자·로고, `noOutline`) + 움직이는 파츠(+ `<파츠>_fine`) + 앵커 |
| 루트 속성 | `outline`, `fpOffset`("x,y,z", three.js 카메라 공간), `fpRot`("x,y,z" 도) |
| 움직이는 파츠 | 오브젝트 원점 = 회전축 또는 기준점. `move`="x,y,z"(three.js 부모 공간, 전체 행정), `rotAxis` + `rotDeg`(숫자 또는 `"0,45,90"` 목록) |
| 앵커 | `muzzle`, `grip_support`, `sight_eye`, `eject`, `mag_well` (+ 무기별 추가). 회전 없음. 움직이는 파츠 위 앵커는 그 파츠의 자식 |
| 엠블럼 | 원작 엘프 로고(`public/ui/elf_logo_mono.svg`)를 `hw.elf_logo`가 n각형 데칼로 만든다(SVG 파싱은 `r41.elf_logo_outline` 재사용). SVG가 없으면 `Gun.logo`가 그 자리에 `emblem_slot` 빈 오브젝트를 둔다 |

- **조정간**: `selector`의 `rotDeg` 목록 인덱스는 safe 0, semi 1, auto 2. 카빈 기본 모드는 `semi`를 첫 값으로 두는 것을 권한다(진압반 교범: 단발 우선).

- **탄피**: 엘피니아 `fx.shell: '556'`(소총)·`'9mm'`(권총). 진압반 고무탄은 탄피 대신 작은 플라스틱 덮개를 쓰는 설정이라 `'none'`을 권한다(발사기는 펌프 때 큰 탄피, 전용 탄피 모델이 생기기 전까지 `'12ga'`로 대체).
- **총구 화염**: 엘피니아는 노란 화염(`size 0.12`), 진압반 고무탄은 작고 흰 연기(`size 0.06, color 0xe9f2f0, light 0.6`), 발사기는 `size 0.16, color 0xd8f0ec, light 1.2`.
- **전기충격봉**: `melee: { style: 'thrust', range: 1.5, arc: 35, windup: 0.12, active: 0.1, recovery: 0.38, suppression: 60, ammo: AMMO.shock, fx: 'discharge', status: { kind: 'shock', intensity: 1, duration: 1.2 } }`. 방전 순간 `arc` 파츠를 0.12 s 보이고 `charge_n`을 끈다. 충전이 0이면 `fx: 'none'`, 제압치 20.
- **최루탄**: `payload: { kind: 'gas', radius: 4.5, suppression: 0, edge: 1, status: { kind: 'gas', intensity: 0.8, duration: 3 }, cloud: { duration: 10, radius: 4.5, tick: 0.5, color: 0xd9e8c8 }, shake: 0, impulse: 0 }`. 가스 이펙트는 `vent_top`·`vent_bottom` 앵커에서 나온다. `parts: { pin: 'pin', spoon: 'lever' }`.
- **발사기**: `kind: 'launcher'`, `projectile: { speed: 55, gravity: 9.81, radius: 0.019, lifetime: 4 }`, `payload: { kind: 'he', radius: 2.5, suppression: 40, edge: 0.3, shake: 0.3, impulse: 3 }`(고무 충격탄의 착탄 충격). 최루탄을 장전하면 payload를 위 최루탄 값으로 바꾼다.
- **이동**: 발사기 `moveMul 0.92`, 나머지 1. `equipTime`: 소총·카빈 0.45, 권총 0.35, 발사기 0.6, 전기충격봉 0.3, 수류탄 0.4.

## 8. 헬퍼 사용법 (`home_weapons.py`)

```python
import home_weapons as hw
g = hw.Gun("monatium_pistol")
g.s(hw.sculpt("frame", side_pts, hw.rrect(0.022, 0.034, 0.006), bevel=0.0018, mat="violet"))  # 둥근 몸통
g.f(hw.decal("win", hw.stadium(0.02, 0.007), (-0.012, 0.06, 0.064), mat="dark", **hw.LEFT))   # 스타디움 창
g.f(*hw.holes("hole", (-0.012, -0.03, 0.064), 3, 0.0085, 0.003, mat="dark", **hw.LEFT))       # 구멍 줄
g.logo((-0.0136, 0.0, -0.006), 0.010, mat="gold", **hw.LEFT)       # 원작 엘프 로고 (없으면 emblem_slot)
g.p("slide", *objs); g.pivot("slide", (0, -0.044, 0.062), move=hw.mv(0, -0.03, 0))           # Blender 변위 → three.js
g.anchor("grip_support", (0, 0.174, -0.012), parent="pump")
g.finish("weapons/monatium/monatium_pistol.glb", outline=0.0017, fp="0.11,-0.125,-0.26", fprot="0,6,0")
```
- 데칼 방향 프리셋 `LEFT/RIGHT/TOP/BACK/FRONT`은 (right, up) 쌍이고 법선 = right × up이다. `LEFT`의 u축은 -Y라서 `cx`로 옮기면 뒤로 간다. 데칼 위치는 `center`로 준다.
- 바탕 원판(lift 0.0005) 위 로고는 `lift=0.0011`(기본)로 띄워 깜빡이지 않게 한다.
- `Gun.finish`는 삼각형 12k, 머티리얼 8개를 넘으면 오류로 멈춘다.

## 9. 남은 문제
- **1인칭 팔**: `viewmodels/rita_fp_arms.glb`의 `hold_rifle`·`hold_pistol`은 M4A1·M17 손 위치에 맞춰 구워져 있어 이 무기들과 손이 어긋난다. 팔 빌더(`monatium_sop.build_fp_arms`)가 무기 glb의 `fpOffset`·`fpRot`·`grip_support`를 읽어 무기별 클립을 만들거나 런타임 IK가 필요하다. 근접용 `hold_melee`(전기충격봉)와 고리 손잡이를 쥐는 왼손(MR-37)도 없다.
- **발사기 탄**: 고무 충격탄·최루탄 1발 소품 모델(장전 손 소품)과 전용 탄피가 아직 없다. 탄띠의 2발은 개머리에 붙은 정지 메시다.
- **전기충격봉 `arc`**는 glb에 보이는 상태로 들어 있다. 무기 시스템이 기본으로 숨겨야 한다.
- 시트의 엘피니아 회녹은 프롤로그 캐시·엘피니아 병사 전투복(`#a3ada1`/`#7f8a80`)에 맞췄다. 프롤로그 리타 복장이 다른 색으로 확정되면 `PAL["olive"]`만 바꾸고 두 엘피니아 무기를 다시 빌드한다.

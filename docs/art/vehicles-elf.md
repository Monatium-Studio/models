# 엘프 차량 (vehicles/monatium, vehicles/r41)

엘프가 몰도록 설계한 차량 네 대와 차량 전용 거치 무기 네 정이다. 같은 등급의 인간 차량보다 작고 아담하다. 툰 화풍에서는 귀엽게 보이지만 장비로서는 진지하게 만들었다.
차량 규약은 `docs/art/VEHICLES.md`를 따른다. 진영별 시각 규칙은 `weapons-home.md`(교주 차원)와 `r41-style.md`(R41)에 있다.

- 공용 헬퍼: `art/blender/lib/vehicles_elf.py` (팔레트, 둥근·모따기 덩어리, 껍데기 차체·창 구멍, 데칼·엘프 로고, 바퀴, `Veh`·`Mount` 조립기)
- 스크립트: `art/blender/vehicles/{monatium,r41}/*.py`, `art/blender/weapons/{monatium,r41}/mount_*.py`
- 결과물: `public/models/vehicles/{monatium,r41}/*.glb`, `public/models/weapons/{monatium,r41}/mount_*.glb`

```bash
npm run model -- art/blender/vehicles/monatium/monatium_riot_apc.py
npm run shot -- vehicles/monatium/monatium_riot_apc.glb --views front,34,side,top
npm run model -- art/blender/weapons/monatium/mount_mr37a.py
npm run shot -- weapons/monatium/mount_mr37a.glb --views side,34,top,muzzle
```

## 3. 공통 규약 (VEHICLES.md 보충)

- **좌표**: 1 BU = 1 m, 정면 -Y, 차량 왼쪽 +X(`_L`), 원점 = 바퀴 발자국 가운데 아래 지면(z=0). 타이어 바깥 끝 = `radius` = 지면이다.
- **노드**: `body`(빈 오브젝트) > `body_<머티리얼>` 메시 + `body_decals`(noOutline). `turret` > `turret_<머티리얼>`, `gun_pitch` > `gun_<머티리얼>`. 움직이는 파츠는 메시 하나로 합치고(`wheel_*`, `door_*`, `hatch_*`, `light_*`), 데칼은 `<파츠>_fine`(noOutline) 자식이다.
- **조준 노드** (노획 미군 세트 `vehicles_us`와 같은 규칙)
  - `turret`, `gun_pitch`는 회전 없이 차량 좌표계 그대로다(three.js 정면 +Z). `turret`은 three Y축으로 돈다(+ = 차량 왼쪽). `gun_pitch`는 three X축으로 돈다(포구가 위로 가면 -X 회전).
  - `mount_*`는 Blender Z축으로 180° 돌아 있고 `restYawDeg: 180`을 단다. 무기 glb(총구 +Y)를 **변환 없이 자식으로** 붙이면 차량 정면을 본다. 런타임은 rest 회전 위에 로컬 yaw(Y)와 pitch(X, + = 위)를 곱한다.
  - `yawMin = yawMax = pitchMin = pitchMax = 0`인 거치(APC 포탑의 두 무기, IFV 공축)는 부모(`gun_pitch`)가 조준한다.
- **거치 무기 속성**: `weapon`(무기 정의 id), `model`(붙일 glb 경로. 차량 메시에 들어 있으면 `""`), `seat`(조작 좌석), `yawMin/yawMax/pitchMin/pitchMax`(도), `restYawDeg`. `muzzle_<id>` 빈 오브젝트를 `mount_<id>` 아래에 두었고, 위치는 무기 glb의 `muzzle`과 같다.
- **좌석 추가 속성**: `controls`(조작하는 노드, 쉼표 구분. 운전석은 `drive`, 그 밖에 `turret,gun_pitch,mount_coax`, `mount_mr12`, `drone_tube` 등. 노획 미군 세트와 같은 형식), `view`(`turret_camera`, `gunner_sight`, `vision_blocks`, `tablet` 등 카메라 힌트), `pose`(`ride` 오토바이, `sit`, `stand`), `facing`(`inward` 병력칸 좌석. 노드 자체는 규약대로 -Y가 정면).
- **바퀴 속성**: `radius`, `steer`(1 = 조향), `width`. 사이드카만 `drive`(1 = 구동)를 단다.
- **껍데기 차체**: APC와 IFV 차체는 속이 빈 껍데기다(두께 4 cm, 안쪽 면 = 실내색 `mv_cabin`/`rv_cabin`). 운전석 앞 유리, 운전석 옆 창, IFV 겹눈 시야창은 **실제 구멍**이고 반투명 유리(`mv_glass` 0.35, `rv_glass` 0.4)를 끼웠다. 좌석 카메라가 창 너머로 밖을 본다. 병력칸 창은 불투명 렌즈 데칼이다.
- **충돌**: `COL_*`는 단순 볼록 형상이다. 머티리얼은 완전 투명 `UNLIT_collider`(alpha 0)이고 `collider: 1`, `noOutline: 1`을 단다. 그래서 뷰어에서도 보이지 않는다. 포탑 충돌체(`COL_turret`)는 `turret`의 자식이다.
- **이펙트·발사 지점** (빈 오브젝트): `exhaust_<n>`, `gas_tube_L/R`(APC 최루탄 발사관, `fx: teargas`, `count: 3`), `smoke_L/R`(IFV 연막, `fx: smoke`), `drone_tube_<n>`(드론 발사 칸, `drone: drones/drone_swarm.glb`, `launch: up|side`), `eject_main`.
- **켜고 끄는 등**: `light_head_L/R`, `light_tail_L/R`(UNLIT 메시). APC의 `light_beacon`은 경광등이다(`light: beacon`, `color`). 깜빡임용이다.
- **머티리얼 이름**: 모나티엄 `mv_<키>`, R41 `rv_<키>`. 거치 무기는 머티리얼 10개 이하, 삼각형 8k 이하에서 `Mount.finish`가 멈춘다. 차량은 `Veh.finish`의 `budget`(렌더 삼각형, 충돌체 제외)을 넘으면 멈춘다.

### 4.1 MRV-1 '요람' (`monatium_riot_apc`)
- 이름: 진압반 무기 이름 규칙(재우고 혼내는 이름)을 따랐다. 분대를 품고 흔들리는 요람이다.
- 형태: 둥근 식빵 차체(옆모습 ∩ 단면, 아래 2톤), 청록 비살상 띠와 `비살상`·`모나티엄 진압반` 글자, 고양이 눈 모양 앞 유리 두 장 + 접이식 격자, 스타디움 옆 창 + 막대 격자, 반쯤 감은 눈꺼풀 차양의 전조등, 밀대(경고 줄 + **청록 고무 발바닥 패드**: 큰 패드 1 + 발가락 4), 경광등(시안 칸) + 탐조등, 뒤 둥근 해치, 안테나 둘(시안 끝), 문 엠블럼(남보라 원판 + 금테 + 금색 엘프 로고), 지붕 공중 식별 번호 `07`, 앞바퀴 뒤 문, 뒤 경사로 문.
- 포탑: 고양이 머리 돔(귀 = 확성기 판 + 은색 슬롯, 아몬드형 쌍둥이 카메라 눈, 입 자리 방송 그릴, 이마 조준경), 뒤 짐칸 양옆 **최루탄 발사관** 3관씩(청록 마개 + 노랑 띠), 받침대(수염) 양끝에 거치 무기 둘.
- 실내: 계기판(시안 막대 화면 둘), 조향 고리. 운전석·지휘석 앞 유리와 옆 창은 구멍이다.

  - 그 뒤 `npm run shot -- _tmp/<이름>.glb --mode fpbody --pitch -6`
- 확인한 것
  - 엘프(키 1.2 m)는 APC 차체(1.70 m)보다 작다
  - 사이드카 핸들(0.96 m)보다 크다
  - IFV 차체 1.58 m, 습격차 조종칸 0.92 m
  - 좌석 시점
    - APC 운전석: 앞 유리 + 격자 + 계기판. 처음 자리(눈 1.36)는 앞 유리(경사면 1.33~1.60)보다 낮고 멀어 하늘과 격자만 보였다. 눈을 유리 가운데 높이(1.48)로 올리고 0.14 m 앞으로, 격자 세로 봉을 11개 → 4개(눈 앞을 비움, 0.8 → 0.6 cm)로 줄였다
    - APC 포수: 받침 양끝 총구
    - 사이드카 운전수: 고양이 귀 덮개 + 계기판
    - 사이드카 사수: MR-12 가늠자 + 방패
    - IFV 운전수: 겹눈 시야창
    - IFV 포수: 기관포
    - 습격차 운전수: 운전대 + 오각 화면
    - 습격차 사수: M-4 가늠자 + 시야창

## 7. 남은 문제 · 차량 시스템 메모
- **사이드카 바퀴는 셋**(`wheel_FL`, `wheel_RL`, `wheel_RR`)이고 `wheel_FR`이 없다. 구동은 `wheel_RL`만이다(`drive` 속성). 무게 중심이 오토바이 쪽(+X)에 있으니 물리 쪽에서 질량 중심을 바퀴 셋의 가운데로 잡거나, 사이드카가 들리는 연출을 넣는다.
- 병력칸 좌석(`seat_passenger_*`)은 실내가 단색 벽이라 1인칭으로 볼 것이 거의 없다. 하차 전까지 3인칭이나 페이드를 권한다.
- 탑승 연출(`src/game/vehicles/boardingRoutes.ts`)이 지나가는 문·해치 뒤에는 실제 출입구를 뚫었다: MRV-1 앞 옆문 둘과 뒤 경사로, V-21 조종수 해치와 뒤 경사로(문판보다 3~4 cm 안쪽, 닫으면 문판이 덮는다). MRV-1은 예산(22k)을 지키려고 바퀴집 커터를 32 → 24각으로 줄였다. 지붕 해치(MRV-1 `hatch_roof`)는 아직 구멍이 없다.
- V-21 병력칸과 앞 차체 사이 허리는 속이 찬 덩어리다. 포탑 승무원 탑승 연출은 병력칸 앞에서 조준경으로 넘어간다.
- V-21 배 띠(`abd_stripe`, `abd_edge`)는 고리라서 양 끝 팔각 마개를 지웠다. 마개가 있으면 병력칸 안을 판처럼 가로막아 승객석 시야가 주황·검정 판으로 덮였다.
- 병력칸 승객석은 창이 없어 맞은편 벽과 열린 경사로만 보인다 (모든 장갑차 공통).
- 드론 발사 칸(`drone_tube_*`)은 빈 칸이다. 발사 때 `drones/drone_swarm.glb`를 그 자리에서 생성한다. 뚜껑 애니메이션은 없다.
- 경광등 `light_beacon`과 등 메시는 켜진 색으로 들어 있다. 끄려면 런타임이 머티리얼 색을 어둡게 하거나 메시를 숨긴다.
- R41 차량을 노획해 리타가 몰 수도 있다(시나리오 3막 이후). 좌석 시점은 R41 차량도 엘프 눈높이에 맞췄다.

# 에르피엔과 세계수 (`erpien_kit`), 에르피엔 깃발 (`erpien_flag`)

모든 에르피엔 장면이 같은 디자인을 쓰도록 세계수 엘드르와 그 둘레의 요정 왕국을 한 키트로 만든다. 깃발은 5장.
시나리오의 배치 규칙은 `docs/scenario.md` 머리말 '세계 배치'를 따른다.

- 키트: `art/blender/lib/erpien_kit.py`
- 쓰는 세트: `epilogue_coronation`(가까운 장면), `m8_overlook`, `m9_assault`, `cine_holywar`, `cine_finale`, `interlude_arrival`, `interlude_construction`(원경)

## 1. 원작 근거 (2026-11-02 조회, 나무위키)

| 문서 | 확인한 것 |
|---|---|
| 「요정(트릭컬 리바이브)」 에르피엔 안내서 서문 | 세계수를 세상의 중심으로 삼아 요정들의 왕국은 엘리아스 중심에 자리 잡았고, **왕국 한가운데 세계수를 모셨다**. 왕국 외곽에는 호수가 있고 강이 흐르며 그 둘레가 농경지다 |
| 같은 문서 각주 | **왕궁 주변과 도시에 성곽이 있는 이중 성벽 구조**. 수도는 정령산 정상에서도 잘 보일 만큼 넓다 |
| 「세계수(트릭컬 리바이브)」 | 요정 왕국에 자리 잡은 거대한 나무, 엘리아스의 근간 |
| 「엘리아스 침공전」 | 흑뉴아는 반물질 중성자탄을 **세계수와 에르피엔을 향해** 쏜다. 전선은 '에르피엔 세계수 기준' 동부·서부로 나뉜다 |

레퍼런스 그림(요정 문서의 에르피엔 전경, '티켓 투 더 문' 엘리아스 전경)은 스크래치패드에서만 봤고 저장소에 넣지 않았다. 읽은 인상:
- 수관: 뭉게구름처럼 둥글게 부푼 큰 덩어리들이 모인 돔. 폭이 높이보다 넓다. 위는 밝은 연두, 아래는 짙은 초록 그늘
- 줄기: 여러 가닥이 꼬여 오른 굵은 줄기. 밑동이 넓게 벌어진다
- 밑동의 성: 흰 석벽, 청록 원뿔·양파 지붕, 금 장식. 가운데 높은 첨탑과 둘레의 가는 탑들
- 성 밖: 붉은·보라·주황·청록 지붕의 마을. 엘리아스 전경에서는 세계수 돔을 시가 고리와 길이 동심원으로 두른다

## 2. 디자인 [오리지널]

형태와 배치는 모두 새로 만들었다. 크기는 나무 높이 h에 비례한다.

### 2.1 세계수 `world_tree(C, cx, cy, z0, h, detail=0|1)`

| 부분 | 비율 (h 기준) | 만드는 법 |
|---|---|---|
| 밑동 | 반지름 0.08h | 가운데 심(짙은 껍질) + 꼬인 가닥(가까이 7, 멀리 4). 가닥은 밑에서 벌어지며 0.55 rad 꼬여 오른다 |
| 판뿌리 | 끝 0.15~0.18h | 밑동에서 바깥으로 휘어 내려 땅에 박히는 관 (가까이 10, 멀리 6) |
| 큰 가지 | 수관 속 0.48~0.6 R | 가닥이 수관 밑에서 그대로 벌어져 수관 속으로 들어간다. 가까이는 곁가지 둘씩 |
| 수관 | 밑 0.36h, 반지름 R = 0.6h(폭 약 1.3h), 꼭대기 h | 아래 그늘 판(짙은 초록, 납작) → 속 돔 → 가장자리 고리 16 → 가운데 고리 12 → 위 고리 7 → 꼭대기 → (가까이) 뭉게 혹 20. 덩어리마다 다른 각도로 돌려 같은 분할의 구가 맞붙지 않게 한다 |

색: `eld_bark #8c6c58`, `eld_bark_d`, `eld_bark_l`, `eld_leaf #64a865`, `eld_leaf_l #86c27a`(위), `eld_leaf_d #478a57`(아래).
삼각형: detail 1 약 14k, detail 0 약 3.7k.

### 2.2 왕국 `kingdom(C, cx, cy, z0, h, face=..., skip=..., palace_scale=...)`

세계수 밑동에서 바깥으로:

| 고리 | 반지름 (h 기준) | 내용 |
|---|---|---|
| 왕궁 단 | 0.25h | 밑동을 두른 낮은 원형 단(금 테) |
| 왕궁 | 0.17~0.24h | 날개 건물 12채(흰 벽, 청록 박공 지붕, 금 처마 띠)가 밑동을 고리로 두른다. 날개 사이 안·바깥에 탑(원뿔·양파 지붕). 보는 쪽(face) 정면에 정문 건물, 왕궁에서 가장 높은 양파 첨탑, 쌍탑 |
| 안쪽 성벽 | 0.28h | 왕궁 성곽 + 탑 14 |
| 시가 | 0.315~0.66h | 고리 거리를 따라 줄지은 박공집(붉은·청록·보라·주황·파랑 지붕), 첨탑 신전 몇 채 |
| 바깥 성벽 | 0.72h | 도시 성곽 + 탑 20 + 큰길마다 문루 |
| 큰길 | 6갈래 | 하나는 face(보는 사람·세트 쪽). 큰길 자리는 집과 성벽을 비운다 |

- `palace_scale`: 왕궁 건물 높이와 탑 굵기만 줄인다(고리 반지름은 그대로). 원경은 1(원작 그림처럼 성이 밑동에서 크게 읽힘), 대관식 세트는 0.5(세트의 왕성 정문 홀과 키를 맞춤).
- `skip(x, y)`: 가까운 세트가 이미 지은 자리를 비운다(대관식: 왕성·안뜰·대로와 그 둘레 정원).
- `lit`: 새벽·해 질 녘 장면의 창불 머티리얼 키(`win_lit`, `lamp_warm`).
- 색: `erk_wall #f7f2ea`, `erk_wall_d`, `erk_roof #3f9c88`, `erk_roof_l`, `erk_roof_r/p/o/b`(마을), `erk_gold #e6bd6e`.
- 삼각형: 원경(palace_scale 1) 약 10.4k.

### 2.3 공기 원근 `haze(color, k)`
수 km 원경은 키트 색을 하늘·안개 색 쪽으로 섞는다(레벨이 `C`를 만들기 전에 부른다). M8 `#9aa7bd` 0.36(새벽), M9 `#e9b79c` 0.2(해 질 녘). 컷신 세트는 `cine_kit.night()`가 키트 색까지 함께 물들인다.

## 4. 렌더 규칙

- 겹친 면 없음: 금 테·처마 띠는 뚜껑 없는 옆면만 쓰고, 왕궁 단의 금 테는 단 옆면 밖으로 0.5 m 나온다. 수관 덩어리는 서로 다른 각도로 돌린 구라 맞붙은 평면이 없다.
- 아웃라인: 원경은 `far`(굵기 0.07 m, level 모드라 1.3 px 아래로 가늘어지면 스며 사라진다) 또는 아웃라인 없는 그룹. 대관식의 세계수는 그룹 굵기 0.55 m라 150~450 m에서 1~3 px 선이 남는다.
- 그리기 호출: 대관식 세트의 `worldtree`·`kingdom`·`palace_garden`·`woods`·`far` 묶음은 `bake=1`이라 불러올 때 묶음마다 메시 하나 + 외곽선 하나로 합친다(`LevelLoader` → `art/bake.ts`, 약 50개 → 10개). 남쪽 하늘에서 세트 전체를 내려다보는 새 전경 때문에 안뜰·단상·왕성·성벽·회랑·화단·퍼레이드 대로 묶음도 `bake=1`로 합쳤다(대로 하나가 메시 31 + 외곽선 21 → 4 + 3). 원경 세트는 묶음 하나에 머티리얼 15개 안쪽이 더해진다.
- 성능: 원경 한 벌 약 13k, 대관식 세트 약 22k 삼각형(세계수 14k + 왕국 8k).

### 5.2 변형 [오리지널: 3D 형태와 비율]

| 함수 | 모양 | 쓰는 곳 |
|---|---|---|
| `standard()` | 깃대 + 깃대 옆에 매단 물결 천(가로세로 원작 비율) + 금 술(끝·아래) + 깃대 쪽 금 줄 둘 + 창끝 | 성전군 기수(`carried()`), M9 진지 깃발(`battlefield_kit.fairy_banner`), 퍼레이드 차 펜더 깃발 |
| `banner()` | 금 봉에 거는 세로 천 + 위 금 줄 둘 + 아래 금 술. 나비 폭 = 천 폭 × 0.6 | 대관식 왕성·회랑·성벽·대로 상가·개선문·단상 |
| `hand_flag()` | 막대 + 작은 물결 천 | 군중 손깃발 `crowd_*.glb` |
| `far_flag()` | 평판 천 + 성긴 나비 | 대관식 탑 꼭대기·가로등, 성전군 천막, M8 망루 |
| `emblem()` | 나비 문장만, 면에 그린다(노란 바탕 + 금 윤곽선 + 말린 선) | 성전군 보급 상자 스텐실(`battlefield_kit.butterfly`), 대관식 융단·단·아치·성문·개선문 문장 |
| `badge()` | 두께 있는 나비 문장: 노란 바탕 판 + 한 단 낮은 금 윤곽선 테 + 말린 선. `both`는 앞뒤 대칭 조형, `fine`은 곡면에 감쌀 때(`warp_sink`) 고른 격자 분할 | 경비대 샤코(앞면 곡면에 감쌈)·부츠 원판·폴랑 망토, 네르 부츠·대관식 브로치(`fairy.emblem`), 퍼레이드 차 문·그릴·꽁무니 메달과 보닛 장식, 대관식 지붕 꼭대기 조형 |
| `outline()`, `edge_outline()`, `STROKES`, `grid_tris()` | 도안 자체(외곽선, 윤곽선 바깥 둘레, 말린 선)와 오목 외곽선 격자 분할 | 경비대 머스킷 엠블럼(개머리 곡면 부조, `fairy_guard_musket.py`) |
| `BUNTING` | 깃발 줄 삼각기 색 (초록·노랑) | 대관식 깃발 줄 |

- 색 키: `erf_green`, `erf_yellow`, `erf_gold`(나비 윤곽선·안쪽 선과 금 술·창끝이 같은 색), `erf_pole`. 소품 머티리얼 4개 안.
- 출력: `sink.mesh(key, layer, verts, faces)` 하나. `city(C)`(도시·레벨 키트), `bm_sink(get, remap)`(퍼레이드 차처럼 자기 누적기가 있는 빌더), `buf_sink(buf, mats)`(엘프 키트 Buf).
- 겹친 면: 천(main) → 나비 바탕·윤곽 고리·금 줄(under) → 안쪽 선(fine). 윤곽선은 바탕 둘레의 고리 띠라 바탕과 겹치지 않는다. 물결 천은 열마다 평면이고 문장을 열 경계에서 잘라 각 열 위에 놓는다. 금 술은 천 가장자리 밖에 이어 붙인다.
- 삼각형: 드는 군기 1.7k, 레벨 군기(res 1) 약 0.8k, 현수막 약 0.28k, 손깃발 약 0.23k, 원경 깃발 64~76. 문장(res 1) 약 0.11k, 배지(res 1, 말린 선 없음) 약 0.4k, 배지(low, 말린 선 포함) 약 0.39k.
- 배지 면 분할: 앞면을 둘레 고리 + 안쪽으로 나눈다. 아웃라인 헐(`toon.ts`)은 정점을 이웃 면 법선 평균으로 미는데, 오목한 홈끼리 잇는 긴 삼각형이 있으면 헐이 뒤집혀 면을 가로지르는 금이 보인다. 인물(헐이 두꺼움)에는 말린 선을 넣지 않는다(`fairy.emblem`).
- 확인: `EF_LINEUP=1 npm run model -- art/blender/props/erpien_flag.py` → `props/erpien_flag_lineup.glb`(변형 비교, 커밋 안 함).

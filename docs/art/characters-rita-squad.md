# 리타와 특수작전부 분대

주인공 리타와 분대원 4명(사브르, 로나, 제스티, 케이트)의 설정, 디자인 근거, 팔레트, 삼각형 수를 정리한다. 다섯 명 모두 **[오리지널]** 인물이고, 특수작전부라는 부서도 오리지널 설정이다.

- 공용 모듈: `art/blender/lib/monatium_sop.py` (복장·장비 헬퍼, 팔레트 `PAL`, 리타 프리셋, 엘피니아 전투복, 1인칭 팔 솔버)
- 스크립트: `art/blender/characters/rita.py`, `rita_prologue.py`, `squad_{sabre,rona,jesty,karen}.py`, `art/blender/viewmodels/rita_fp_arms.py`, `rita_prologue_fp_arms.py`
- 결과물: `public/models/characters/rita*.glb`, `squad_*.glb`, `public/models/viewmodels/rita*_fp_arms.glb`
- 근거 문서: `docs/scenario.md` 1장, `docs/art/reference-notes.md` 5·6장, `docs/art/r41-style.md`, `docs/art/ELF_KIT.md`

```bash
npm run model -- art/blender/characters/rita.py
npm run shot -- characters/rita.glb
npm run shot -- characters/rita.glb --focus rita_face --views front --morph held_back:1
npm run shot -- weapons/us/m4a1.glb --mode fp --arms viewmodels/rita_fp_arms.glb --armsanim hold_rifle
npm run shot -- weapons/us/m17.glb --mode fp --ads 1 --arms viewmodels/rita_fp_arms.glb --armsanim ads_pistol
```

> 머리카락은 키트 **헤어 v2**(한 장의 매끈한 셸, 끝에서만 갈라지는 다발, 속층, 흔들림 본)로 만든다. 인물별 구성은 1.5절, 키트로 안 되는 부분을 메운 보조 함수는 1.6절에 있다.

## 1. 특수작전부 현장 복장 (시각 언어)

교주 차원 모나티엄 진압반 산하의 정찰·침투·표적 지정 부서다. 진압반 시각 언어(자줏빛 회색 진압 장비, 남보라 지휘색, 금색은 지휘관만)를 그대로 쓰고, 정찰 부서다운 요소를 더했다.

### 1.1 공통 요소 (같은 부대로 보이게)

| 요소 | 내용 | 이유 |
|---|---|---|
| 전투복 | 남보라 회색 상의(차이나 칼라, 앞여밈, 은색 단추) + 한 단 어두운 바지(블라우징) | 진압반 지휘색 `#706478`을 현장복으로 누름. 밝은 회색인 R41 전투복과 명도·채도로 갈림 |
| 장비 | 자줏빛 회색 웨빙·파우치·벨트, 은색 버클 | 원작 진압반 장비색 `#655d64`, `#4b424a` |
| **청록 부서 스카프** | 같은 천을 사람마다 다르게 맨다 | 멀리서도 '특수작전부'로 읽히는 단일 표식. 모나티엄 네트워크·창고 관리색 계열 |
| 회청록 장갑 | 스카프 색을 누른 장갑 | 1인칭에서 검은 총몸·보라 소매와 손이 구분된다. R41은 손가락 없는 검은 장갑 |
| HUD 헤드셋 | 머리 밴드 + 귀 위 단말 + 시안 LED (+ 접어 올린 HUD 렌즈) | 시나리오 3장: 리타의 HUD = 모나티엄 코어 AI 망에 연결된 진압반 장비 |
| 부서 휘장 | 남보라 원 + 은색 나침반 바늘(세로 마름모) + 청록 점, 왼팔 위 | '먼저 들어가 길을 가리키는 사람'. 기하 도형만 써서 원작 문양과 겹치지 않음 |
| 계급장 | 남보라 사각 + 은색 막대(일반), **금색 막대는 분대장만** | 진압반 규칙: 금색은 지휘관만 |

### 1.2 개인 변형 (같은 천, 다른 매듭)

| | 스카프 | 머리 장비 | 몸 장비 | 소매 |
|---|---|---|---|---|
| 리타 | `tails` 목에 감고 등 왼쪽 매듭, 긴 꼬리 둘 | 헤드셋 + 접어 올린 HUD 렌즈 | 낮은 가슴 장비(탄창 3, 거꾸로 단 칼, 표지등), 허벅지 권총집 | 표준 + 왼 손목 단말 |
| 사브르 | `neat` 목 앞 단정한 매듭 | 범프 헬멧(앞 금줄) + 붐 마이크 | 판 조끼 + 지도 창 행정 파우치, 송수화기, 어깨 보호대 | 표준, 금색 계급 2줄 |
| 로나 | `cowl` 어깨까지 덮는 두툼한 두건 | 챙 넓은 정글모 + 위장 천 조각 | 거리측정기, 몸을 가로지르는 멜빵, 긴 탄창 파우치 2, 어깨 위장 천 | 표준 + 팔꿈치 보호대 |
| 제스티 | `arm` 왼팔 위팔에 묶음 | 진압 헬멧(통풍구·앞 챙) + 올린 고글 | 무전기 배낭 + 뒤로 휜 채찍 안테나, 폭약 블록, 기폭선 실패 | 걷어 올린 소매 |
| 케이트 | 두건(`bandana`)으로 머리에 동여맴 | 둥근 안경 | 의무 배낭(청록 원 + 흰 더하기), 의무 파우치 3, 지혈대 | 표준 + 흰 완장 |

### 1.3 R41과의 구분 (`r41-style.md` 6장 대비)

| | 특수작전부 | R41 소총병 (PV 기준) |
|---|---|---|
| 전투복 | 남보라 회색, 바지는 더 어둡게 | 회갈색이 섞인 **밝은 회색** |
| 머리 | 맨머리·범프 헬멧·정글모·두건 (인물마다 다름) | 밝은 회색 헬멧 + 연기색 고글 (통일) |
| 포인트 색 | 청록 스카프, 시안 발광, 금(분대장만) | 앰버 휘장, 마젠타 기계 발광 |
| 장갑 | 회청록, 손가락까지 | 짙은 회색, 손가락 없음 |
| 형태 | 둥근 덩어리 (키트 rbox) | 모따기 덩어리, 육각 부품 |
| 먹선 | 붉은 갈색 (키트 공통) | 장비만 차가운 보라 |

### 1.6 헤어 v2 보조 함수 (`monatium_sop`)

| 함수 | 하는 일 | 왜 필요한가 |
|---|---|---|
| `hair_locks(h, fn)` | 키트가 정한 다발 목록(`h._locks()`)을 `fn(locks)`로 고친다 | 키트 `sides()`는 좌우 대칭이라 리타의 왼쪽 긴 가닥을 낼 수 없다. 긴 가닥을 셸의 옆머리 다발 자체로 늘려야 셸과 한 장으로 이어지고 쐐기가 생기지 않는다. 케이트의 일자 앞머리(뭉툭한 끝 `p`)도 이걸로 낸다 |
| `hair_tail(h, …, out=)` / `hair_twintails(h, …)` | 키트 `Hair._tail`을 `out`(셸 밖으로 뻗는 정도)을 정해 부른다 | 키트 `ponytail()`은 `out=1.25`, `twintails()`는 1.0으로 고정이라 낮은 꼬리가 옆에서 수평으로 튀어나온다 |
| `hair_tuft(h, …)` | 짧게 묶은 꽁지 한 다발 + 끈 + `hair_tail_01/02` | 키트 꼬리는 긴 포니테일용 S자(옆으로 3.5 cm 휨)라 12 cm 꽁지는 갈고리처럼 휜다 |

- 꼬리·꽁지는 따로 만든 버퍼를 `<이름>_hair` 노드에 합친다. 키트 헬멧 `squash`는 머리 중심에서 잰 높이각으로 눌러서, 셸 밖으로 나온 꼬리 뿌리를 헬멧 테 근처로 보고 납작하게 눌러 버리기 때문이다.
- `hair_tail`은 키트 끈(반지름 0.33 × 굵기)이 꼬리 뿌리 단면(반폭 0.375 × 굵기)보다 작아 묻히는 문제를 끈 정점만 1.32배 키워 메운다.
- 모자 아래 해상도 힌트: `cap(segs=18)`은 열을 성글게, `rows=4`는 위쪽 행 간격을 1.8배로 넓힌다. 두건처럼 **테가 보이는 머리 한가운데를 지나는 모자**에는 `rows`를 주지 않는다. 행이 성글면 테 위아래 정점 사이 면이 모자 면을 뚫고 나온다.

## 2. 리타 (주인공)

### 2.1 설정 요약 (`docs/scenario.md` 1장)
- 지구 침공 때 정찰 침투조였지만 출격 대기만 하다 포로가 됐다. "이번엔 먼저 들어간다."
- **과묵한 주인공.** 대사가 없으니 실루엣·표정·몸짓으로 감정을 전한다.

### 2.2 디자인

| 요소 | 결정 | 근거 |
|---|---|---|
| 머리 | **구리빛 붉은 비대칭 단발**: 오른쪽으로 쓸어 넘긴 앞머리, 오른쪽 옆머리는 볼 위에서 끊기고 **왼쪽만 어깨까지 긴 한 가닥**(셸 다발을 늘려 한 장으로 이어짐, 흔들림 본 `hair_side_L_*`), 목덜미의 짧은 꽁지(청록 끈, `hair_tail_*`) | 회보라 복장과 보색 대비(구리 ↔ 청록 스카프). 원작 진압반(칸나 연금발 포니테일, 캐시 회흑 땋은 머리, 알레트 갈색 단발)과 색·모양이 겹치지 않음 |
| 눈 | 호박색, 기본 표정이 살짝 내려앉은 윗눈꺼풀 + 일자 눈썹 + 작고 곧은 입 | 무표정만으로 '과묵함'이 읽히게 |
| 스카프 | 등 왼쪽 매듭에서 긴 꼬리 둘이 바깥으로 흩날림 | 뒤·옆에서 보는 3인칭(컷신, 분대원 시점)에서 '먼저 들어가는 사람'의 움직임 |
| HUD 렌즈 | 오른쪽 귀 위 단말에서 뻗은 팔 끝, 눈썹 바깥 위로 접어 올린 시안 렌즈 | 표정(눈)을 가리지 않으면서 HUD 장비를 보여 준다. 2막(HUD 꺼짐)에서는 렌즈 발광만 끄면 된다 |
| 장비 | 낮은 가슴 장비(탄창 파우치 3 + 칼 + 표지등), 허벅지 권총집(M17), 물통, 덤프 파우치, 무릎 보호대, 왼 손목 안쪽 단말(나침반·지도) | 정찰병의 가벼운 장비. 손목 단말은 1인칭에서 소총을 쥐면 보인다 |

### 2.3 표정 (셰이프 키)
키트 기본 5종(`blink serious surprised pained smile`)에 과묵한 주인공용 3종을 더했다. `expr=`로 넣어 교정 키 `blink_<표정>`이 자동으로 생긴다(런타임 규칙 `blink_<표정> = blink × <표정>`, ELF_KIT.md 6장).

| 키 | 쓰임 | 모양 |
|---|---|---|
| `determined` | 결의. 돌입 직전, "이번엔 먼저" | 윗눈꺼풀을 낮추고 안쪽을 눌러 눈을 가늘게, 동공 약간 작게, 눈썹 안쪽 내림, 입을 꾹 다묾 |
| `weary` | 지침. 2막 암흑, 수용소 | 무거운 눈꺼풀, 시선 아래, 눈썹 안쪽이 살짝 들림, 입이 조금 벌어짐 |
| `held_back` | 억누름. **프롤로그 끝 '출격 명령이 끝내 오지 않는' 장면** | 눈은 뜬 채 동공이 작아지고, 아래 눈꺼풀이 올라오고(울컥), 눈썹 안쪽이 올라가며 입술을 깨묾(작은 물결) |

모든 표정에서 홍채 위쪽이 윗눈꺼풀에 잘리도록 두었다(ELF_KIT.md 6장).

### 2.4 1인칭 몸 규약
- `socket_eye`(head 본), `fpHide`: `rita_head`·`rita_hair`·`rita_hair_in`·`rita_face` = head, `rita_arms` = arms. 스카프 목 고리는 head 그룹(내려다볼 때 목 둘레가 화면을 덮지 않게), 꼬리는 body. 왼쪽 긴 가닥은 `rita_hair` 안에 있어 1인칭에서 함께 숨는다(뷰어 `--mode fpbody` −60°/−80°, 게임 −70°에서 확인).
- 내려다보기: -60°에 탄창 파우치 덮개, -80°에 가슴 장비 전체·칼 손잡이·표지등이 보인다. 칼 손잡이 끝은 위에서 흰 원판처럼 튀지 않게 어두운 금속으로 했다.

### 2.5 프롤로그 (`rita_prologue.glb`)
지구 침공 당일의 정찰 침투조원. **엘피니아 군 전투복**(알레트·타이다·레이지 계열, `_kit_elfinia_soldier`와 같은 복장·색: 회녹 상의, Y 멜빵, 탄창 파우치 3, 허벅지 파우치, 둥근 헬멧 + 통신기)이다. 얼굴·머리·체격은 같은 리타이고(`rita_hair(helmet=True)`), 헬멧 아래로 앞머리·왼쪽 긴 가닥·꽁지가 나온다. 특수작전부 이전이라 청록 스카프와 HUD 헤드셋은 없다. 복장 함수는 `monatium_sop.elfinia_uniform()`/`elfinia_arms()`.

## 3. 1인칭 팔 뷰모델

| 파일 | 소매·장갑 | 삼각형 |
|---|---|---|
| `viewmodels/rita_fp_arms.glb` | `rita_arms()` = 전신 `rita.glb`와 같은 함수(`RITA_ARMS`) | 5,200 |
| `viewmodels/rita_prologue_fp_arms.glb` | `elfinia_arms()` = 전신 `rita_prologue.glb`와 같은 함수 | 4,664 |

- 루트(아마추어) = 카메라 원점(`socket_eye`), 정면 = Blender +Y(three.js -Z). `hand_q=1.2`, outline 0.0022.
- **클립**: `hold_rifle`(M4A1), `ads_rifle`, `hold_pistol`(M17), `ads_pistol`, `hold_melee`(전기충격봉 `monatium_stun_baton`). **레스트 포즈 = hold_rifle**(포즈를 굳혀 넣음)이라 클립을 재생하지 않아도 소총을 쥔 모습이다. 모든 클립은 양팔 전 본의 위치·회전을 키로 갖는다.
- 무기 시스템이 런타임 두 관절 IK로 손을 무기마다 파지점·`grip_support`에 붙인다. 그래서 클립은 **기본 팔 자세와 손가락 쥠 모양**을 주는 역할이고, 무기마다 클립을 따로 굽지 않는다. 쥠 모양: 소총·권총 오른손은 검지를 편 방아쇠 쥠, 왼손은 받침 쥠, 근접은 양손 주먹.
- **손 목표**: 무기 glb를 직접 읽는다(`weapon_info`). 오른손 소켓 = 무기 원점(파지점)을 `fpOffset`·`fpRot`로 놓은 자리, 왼손 소켓 = `grip_support`. 정조준 클립은 뷰어 `--ads 1`과 같이 `sight_eye`가 원점에 오게 옮긴 무기에 맞춘다(게임에서는 리그 전체를 옮기므로 hold 클립을 그대로 써도 된다).
- **솔버** (`Viewmodel.solve`): 손 목표에서 거꾸로 손목 → 팔꿈치 → 어깨를 정한다. 엘프 팔은 짧아서(어깨~손목 0.24 m) 핸드가드(눈에서 0.53 m 앞)에 닿을 수 없으므로 1인칭 팔의 어깨는 몸통에서 떼어 화면 밖에 둔다.
  - `fore`: 아래팔 방향을 직접 준다(손목 꺾기 = 최소 회전, 보고에 각도 출력).
  - `stretch`: 위팔을 제 축으로 밀어내 어깨 끝을 화면 밖으로 보낸다(두께는 그대로, 팔꿈치 섞임 구간이 늘어남. 1인칭 전용 과장).
  - 키트 아래팔은 비틀기 본이 없어서 엄지 방향 = 팔꿈치 굽힘 방향이다. 그래서 소총 왼손은 '손바닥을 총몸 왼쪽 면에 대고 손가락을 위로 넘겨 감싸는' 자세(`base="side"`)로 비틀기 없이 팔을 화면 아래로 뺐다.
- **포즈 표** `monatium_sop.RITA_FP_POSES`(두 팔 뷰모델 공용):

| 클립 | 오른손 | 왼손 |
|---|---|---|
| hold_rifle | 손잡이 22° + 손잡이 축 18°, 검지는 방아쇠 위 | 핸드가드 왼쪽 위에서 손가락이 레일을 넘어 감쌈, 아래팔은 왼쪽 아래에서 비스듬히, 위팔 9 cm 밀어냄 |
| hold_pistol | 손잡이 18° + 축 55°, 아래팔은 오른쪽 아래에서 | 손바닥을 손잡이 왼쪽에 대고(앵커 = 손바닥) 손가락이 앞쪽을 감쌈, 아래팔은 왼쪽 아래에서 |
| hold_melee | 주먹 구멍 축(소켓 z)을 봉 손잡이 축(무기 +Y)에 맞춤, 엄지 = 전극 쪽, 손등 = 무기 +X. 손목을 45° 세워 봉을 들고 아래팔은 화면 아래 | 무기와 무관한 가드 주먹(화면 왼쪽 아래, 엄지 위, 손바닥 오른쪽) |

### 3.1 런타임 IK 규약 (확인 결과)

내보낸 glb의 노드 TRS를 직접 계산해 확인했다(레스트 = hold_rifle).

| 항목 | 값 | 비고 |
|---|---|---|
| 체인 이름 | `shoulder_* → upperarm_* → forearm_* → hand_*` (+ 손가락 `thumb/f1/f2/f3_01·02_*`) | ART_GUIDE 6장과 같다. 좌우 `_L`(캐릭터 왼쪽) / `_R` |
| 뼈 축 | 각 본의 로컬 +Y가 다음 관절을 정확히 가리킴 (내적 1.000) | three.js `bone.rotation`도 같은 축 |
| 팔꿈치 경첩 | 경첩축 `(E−S)×(W−E)` = upperarm +X = forearm +X (내적 1.000). **+X 회전 = 굽힘** | 키트 규칙(아래팔 +X = 팔꿈치 굽힘) 그대로. 레스트에서도 위팔과 아래팔의 X축이 같다 |
| 관절 거리 | 오른팔 위팔 0.128 m, 아래팔 0.112 m. **왼팔 위팔 0.218 m** | 왼팔은 1인칭 `stretch` 0.09 m가 레스트에 들어가 있다. IK는 본 길이 대신 관절 사이 거리를 쓰면 된다 |
| 손 소켓 | `socket_hand_R/L` (hand 본 자식): three.js −Z = 손가락 방향, +Y = 엄지 쪽 | 오른손 소켓 = 무기 원점, 왼손 소켓 = `grip_support`가 오면 된다 |
| 루트 | 아마추어 노드 = 카메라 원점(`socket_eye`), 정면 −Z | 어깨(`shoulder_*`)는 몸통에서 떨어져 화면 밖에 있다 |

전신 모델(`rita.glb` 등)도 같은 이름·축이다(A 포즈라 팔이 곧아서 경첩축만 정의되지 않음).

- 소매 끝 안감 고리(`sleeve_lining`)로 SD 손목의 큰 소맷부리 속 맨살이 1인칭에서 비치지 않게 막았다.
- 점검용 장면: `VM_DEBUG=1 npm run model -- art/blender/viewmodels/rita_fp_arms.py` → `viewmodels/_debug_rita_{rifle,pistol}.glb`(팔+무기). `--anim hold_pistol`을 줘서 본다. 커밋하지 않는다.

## 4. 분대원

리타가 말이 없으니 네 사람이 말을 나눠 맡는다. 이름의 어감을 성격에 살렸다. 모두 1인칭 몸 규약은 필요 없지만 키트 기본(`fpHide`, 소켓)은 그대로 갖는다.

### 4.1 사브르 (분대장) — `squad_sabre.glb`
- **성격**: 칼(사브르)처럼 짧게 끊어 명령한다. 리타의 침묵을 판단으로 바꿔 말해 준다. "리타, 먼저. 둘 따라붙어."
- **실루엣**: 분대에서 가장 큰 키(1.25 m)와 넓은 어깨, 범프 헬멧(앞에 **금줄** = 지휘관), 판 조끼와 지도 창, 왼쪽 붐 마이크, 헬멧 아래로 길게 늘어진 **검푸른 낮은 포니테일**.
- **색**: 머리 `#2f3344`, 눈 강철 파랑 `#5b7ea8`, 금색 계급 2줄(가슴·오른팔), 금색 머리끈.
- **표정 기본**: 날카롭게 내린 눈썹, 바깥 눈꼬리가 살짝 올라감, 입꼬리 약간 올림(여유).

### 4.2 로나 (지정사수) — `squad_rona.glb`
- **성격**: 반쯤 감은 느긋한 눈으로 거리·풍속·탄착을 쉬지 않고 중얼중얼 중계하는 '숫자 수다쟁이'. "4백십, 바람 왼쪽 둘… 맞았다, 그치?"
- **실루엣**: 가장 작은 키(1.14 m), 넓은 챙 정글모와 위장 천 조각, 어깨까지 덮는 두툼한 스카프 두건, 챙 아래로 내려오는 **민트색 낮은 트윈테일**, 가슴 거리측정기, 몸을 가로지르는 멜빵, 팔꿈치 보호대(엎드려 쏘기).
- **색**: 머리 `#86cdb8`, 눈 금빛 `#cf9f34`.
- **원작 '로네'와의 구분**: 로네는 긴 갈색 머리, 머리띠, 한쪽으로 묶은 꼬리다. 로나는 민트색 트윈테일, 정글모, 금빛 눈으로 색·머리 모양·모자를 모두 다르게 했다.

### 4.3 제스티 (통신·폭파) — `squad_jesty.glb`
- **성격**: 농담이 끊이지 않는 무전 담당. 폭약 얘기만 나오면 신이 나고, 리타의 침묵에 혼자 대사를 붙여 준다. "리타가 '잘했어 제스티'래. 방금 눈빛으로."
- **실루엣**: 땅딸막한 체형(팔다리 굵기 1.1, 볼 빵빵), 큰 무전기 배낭과 **뒤로 비스듬히 솟은 채찍 안테나**(분대에서 가장 높은 점, SD 머리를 피해 뒤로 기울임), 진압 헬멧 + 올린 고글, 걷어 올린 소매, 왼팔에 묶은 스카프, 벨트 앞 폭약 블록(노랑 경고 띠)과 기폭선 실패.
- **색**: 머리 `#e98ca6`(헬멧 밖으로 부풀어 나옴), 눈 초록 `#3d9c6c`. 경고 노랑은 교주 측 색이라 R41(노랑 금지)과 겹치지 않는다.
- **표정 기본**: 크게 뜬 눈, 벌어진 웃는 입.

### 4.4 케이트 (의무·후방 경계) — `squad_karen.glb`
- **성격**: 규정과 안전 수칙을 하나하나 짚는 잔소리꾼 의무병. 대답 없는 리타에게도 상태 보고를 받아 낸다. "리타, 대답 안 해도 돼. 맥박은 잴 거니까."
- **실루엣**: 청록 스카프를 두건처럼 동여맨 머리(뒤통수 매듭과 짧은 꼬리), **둥근 안경**, 일자 앞머리의 연보라 단발, 의무 배낭(위에 묶은 천 롤), 허벅지·가슴 의무 파우치, 흰 완장, 지혈대.
- **색**: 머리 `#b9a6d9`, 눈 짙은 파랑 `#4a66ad`. 의무 표식은 적십자 대신 **청록 원 + 흰 더하기 막대**다(보호 표장 회피).
- **원작 '카렌'과의 구분**: 카렌은 긴 짙은 갈색 머리, 머리띠, 앞치마다. 케이트는 연보라 단발, 안경, 두건으로 겹치지 않게 했다. 원래 이름 '캐런'이 카렌과 비슷해 2026-11-02 사용자 지시로 **케이트**(Kate / ケイト)로 바꿨다. 내부 id와 파일명(`karen`, `squad_karen.glb`)은 그대로다.

## 7. 남은 문제

- **모자 아래 머리 (키트 squash)**: 테 바로 아래 눌린 셸은 법선이 고르지 않아 툰 그림자 띠가 들쭉날쭉하다(케이트 두건 뒤쪽이 가장 눈에 띈다). 두건을 0.033으로 띄워 뚫림은 막았지만 얼룩은 남는다. squash가 머리 중심에서 잰 높이각을 써서, 셸 밖으로 멀리 나온 정점일수록 실제보다 높게 판정되는 것도 원인이다.
- **헬멧 아래 앞머리**: 테 밑으로는 다발 끝만 보여서 끝이 뾰족한 삼각형으로 읽힌다(리타 프롤로그·제스티). 앞머리 끝을 눈썹까지 내려 다발로 보이게 했다.
- **꼬리 단면**: 키트 꼬리 관은 단면 10분할이라 클로즈업에서 면이 보인다(로나 트윈테일).
- **게임 내 내려다보기 -60°**: 엔진 `FirstPersonBody.lookDownPushBack`(0.14 m)이 몸을 뒤로 빼서 -60°에서는 가슴 장비가 화면 밖이다. -80°에서는 보인다. 뷰어 `--mode fpbody`는 몸을 빼지 않아 -60°에 파우치 덮개가 보인다.
- **뷰어 fpbody -80°**: 뷰어는 팔·무기를 몸과 같은 깊이 패스로 그려 가슴이 팔을 가린다. 게임은 뷰모델을 따로 그려서 문제없다.
- 1인칭 팔은 SD 체형이라 소매가 굵다. 권총은 `fpOffset`이 눈에서 0.26 m라 소맷부리가 화면 아래를 크게 차지한다. 무기 쪽에서 권총을 조금 더 앞(0.30 m 이상)으로 두면 손이 더 잘 보인다.
- 스카프 꼬리는 아직 흔들림 본이 없다(머리 꼬리·꽁지·리타의 긴 가닥은 `hair_tail_*`, `hair_side_L_*` 본이 있다).
- 1인칭 왼팔 `stretch`는 위팔 섞임 구간을 늘이는 과장이라 3인칭 팔 비율과 다르다. 화면 밖이라 보이지 않는다.

# 노획 미군 화기 세트 (weapons/us)

[오리지널] 엘프들이 지구 포로 생활에서 탈출하며 노획해 온 미군 물자. 모나티엄 창고에 보관돼 있다가 「엘리아스 침공전」에서 리타의 무장이 된다. [원작] 엘프는 지구제 총기와 탄약을 들여와 쓴다.

- 스크립트: `art/blender/weapons/us/*.py`, 소품 `art/blender/props/us_*.py`
- 공용 헬퍼: `art/blender/lib/weapons_us.py` (팔레트, 레일, 스윕, 글자 데칼, `Build` 조립기)
- 결과물: `public/models/weapons/us/*.glb`, `public/models/props/us_*.glb`

```bash
npm run model -- art/blender/weapons/us/m4a1.py
npm run shot -- weapons/us/m4a1.glb --views side,34,top,muzzle --focus m4a1   # --focus 루트 = 바닥 원판 숨김
npm run shot -- weapons/us/m4a1.glb --mode fp                                  # 모델의 fpOffset 사용
npm run shot -- weapons/us/m4a1.glb --mode fp --fp 0,-0.165,-0.115             # 정조준 점검: --fp = -(sight_eye, three.js 좌표)
```

## 1. 공통 규약

| 항목 | 내용 |
|---|---|
| 원점 | 오른손 파지점. 권총 손잡이가 있으면 손잡이 단면 중심, M870은 개머리판 손목 중심, M67은 몸통 중심, M72는 방아쇠 막대 아래 발사관 축 |
| 축 (Blender) | 총구 +Y, 위 +Z, 사수 오른쪽 +X. three.js에서는 총구 -Z, 위 +Y, 오른쪽 +X |
| 노드 구성 | 루트 empty(무기 이름) > `body`(정지 파츠, 머티리얼별 프리미티브) + `body_fine`(각인·핀·스티커, `noOutline`) + 움직이는 파츠 + 앵커 |
| 루트 속성 | `outline`(m), `fpOffset`("x,y,z", three.js 카메라 공간) |
| 움직이는 파츠 | 오브젝트 원점 = 회전축 또는 기준점. 커스텀 속성은 **three.js 부모 공간** 기준: `move`="x,y,z"(전체 행정), `rotAxis`="x\|y\|z" + `rotDeg`(전체 회전, 도). 세부 데칼은 `<파츠>_fine` 자식 |
| 회전 기본값 | 대부분 회전 0 = 기본 상태. M72 마개처럼 열린 각도로 내보낸 파츠는 오브젝트 회전에 값이 들어 있고 회전을 0으로 두면 닫힌다 |
| 앵커 | `muzzle` 총구 끝, `grip_support` 왼손이 **감싸는 부피의 중심**(오른손 원점과 같은 정의), `sight_eye` 정조준 시 눈 위치(광축 위), `eject` 탄피 배출구 바깥, `mag_well` 탄창 입구. 앵커는 회전 없음. 움직이는 파츠 위의 앵커는 그 파츠의 자식이다(M870 펌프, M67 고리, M72 내관) |

Blender 좌표 (x, y, z) → three.js (x, z, -y). 회전은 같은 축 성분끼리 대응한다(Blender X축 회전 = three.js X축 회전, Blender Y축 회전 θ = three.js Z축 회전 -θ).

### 팔레트 (`weapons_us.PAL`)
툰 단색이라 금속은 **명도 차**로 나눈다: `black` #36393f(양극산화·폴리머) < `steel` #5b6068(파커라이징 강철) < `bright` #a9aeb5(핀·나사·노리쇠). 그 외 `coyote` #a88b62, `pvd` #8c7656(M17 슬라이드), `od` #5c6646, `paper` #e9e0c8, `brass`, `red`, `yellow`, 언릿 `reticle`.
`paint` #3fa79c(청록)는 **모나티엄 창고 관리 색 임시값**이다. 진영 색이 확정되면 `PAL["paint"]` 한 줄만 바꾸고 다시 빌드한다.

### 엘프식 흔적 (공통 문법)
실루엣을 건드리지 않는 선에서 무기마다 2~3개씩만 넣었다.
- **창고 태그**: 크림색 종이 태그 + 청록 끈. `MNT` + 관리번호, 한글 부서명(모나티엄 창고, 진압반 병기고, 돌파조, 분대 화기)
- **청록 페인트**: 탄창 바닥판, 개머리판 띠, 스텐실 번호(`MNT-07`, `MNT-M03`, `MNT-L12`)
- **테이프**: M4 핸드가드 왼손 자리 OD 테이프, M17 손잡이 OD 테이프, M72 흰 테이프에 한글 낙서 "후폭풍 주의!"
- 실존 제조사 로고·상표 문구는 없다. 각인은 `PROPERTY OF U.S. GOVT`, `M4A1 CAL 5.56 MM`, `12 GA 3 IN` 같은 일반 표기만 쓴다.

## 4. 헬퍼 사용법 (`weapons_us.py`)

```python
import weapons_us as us
b = us.Build("m4a1")
b.s(us.side("lower", pts_yz, 0.025, bevel=0.0018, mat="black"))   # 정지 파츠
b.f(us.text("mk", "U.S.", 0.005, center, right=(0,-1,0), up=(0,0,1), mat="bright"))  # 아웃라인 없는 데칼
b.p("mag", obj); b.pivot("mag", (0, 0.124, 0.05), move="0,-0.2,0")   # 움직이는 파츠
b.anchor("grip_support", (0, 0.3, 0.09), parent="pump")             # 파츠를 따라가는 앵커
b.finish("weapons/us/m4a1.glb", outline=0.002, fp="0.12,-0.2,-0.26")
```
- `rail()` 피카티니(슬롯 10 mm 간격), `sweep()` 휜 탄창·끈·손잡이, `ytube()` 소염기·발사관, `cut()` 불리언(겹치는 커터 허용), `xform()` 피벗 회전 굽기
- `US_DEBUG=1 npm run model -- ...` 하면 join 전 오브젝트별 삼각형 상위 30개를 출력한다.
- 3차 디테일 원칙: 4 mm보다 작은 돌기(핀, 나사, 리벳, 글자, 스티커)는 아웃라인 헐이 덩어리로 뭉개므로 `b.f()`(noOutline)로 넣는다.

## 5. 남은 문제
- 1인칭에서 무기는 앞을 똑바로 향하고 `fpOffset`은 평행 이동뿐이라 옆면이 좁게 보인다. 엔진에 `fpRot`(약간의 요·피치) 지원이 생기면 무기마다 값을 넣겠다.
- 핍·고스트링처럼 작은 구멍은 아웃라인 헐(2 mm)이 테두리를 두껍게 만든다. 그래서 M72·M249 핍은 실물보다 구멍을 크게 했다.
- M249 `grip_support`는 접힌 양각대 다리다(그립에서 0.455 m 앞). 엘프 팔에 너무 멀면 1인칭 팔 쪽에서 탄통 위(약 y 0.16)를 쥐는 포즈로 바꿔도 된다.
- 모나티엄 진영 색이 아직 확정되지 않았다. 청록 `paint`는 임시값이다.

# 노획 미군 차량 세트 (vehicles/us)

[오리지널] 엘프들이 지구 포로 생활에서 탈출하며 노획해 온 미군 물자 중 차량과 거치 무기. 모나티엄 창고에 보관돼 있다가 「엘리아스 침공전」에 투입된다(`docs/scenario.md` 1장). 미군 화기는 1막 M2에서 병기창고에서 반출한다. M1A1 등 구 기갑병기는 병기창고와 별개인 차고에 모여 있고, 2막 M6 전차전에서 거기서 꺼낸다. 인간 물건이라 1막 끝 둠스데이 정전의 영향을 적게 받았다는 설정이다. 노획 화기 세트(`weapons-us.md`)와 같은 문법을 쓴다.

- 규약: `docs/art/VEHICLES.md`(차량), `ART_GUIDE.md` 7장(무기)
- 스크립트: `art/blender/vehicles/us/*.py`, 거치 무기 `art/blender/weapons/us/{m2,m240_coax}.py`
- 공용 헬퍼: `art/blender/lib/vehicles_us.py` (`weapons_us` 위에 얹음)
- 결과물: `public/models/vehicles/us/*.glb`, `public/models/weapons/us/{m2,m240_coax}.glb`

```bash
npm run model -- art/blender/vehicles/us/humvee.py
npm run shot -- vehicles/us/humvee.glb --views front,34,side,top
npm run model -- art/blender/weapons/us/m2.py
npm run shot -- weapons/us/m2.glb --mode fp            # 거치 사격 시점 (fpOffset, fpRot)
npm run shot -- weapons/us/m2.glb --mode fp --ads 1    # 가늠자·가늠쇠 정렬
```

## 1. 공통

### 도장: 사막 탄 (CARC 686A 계열)
우드랜드 OD 대신 **사막 탄**을 골랐다.
1. 노획 화기 세트가 코요테 탄(M4 개머리판, M17 프레임, M249 탄통 일부)을 쓰므로 같은 물자라는 인상이 이어진다.
2. M1114와 M1A1이 가장 많이 알려진 모습이 사막 탄 도장이다. 실루엣만 보고도 무엇인지 알 수 있다.
3. 툰 셰이딩에서 밝은 탄색 차체 위에 검은 M2, OD 탄통, 청록 관리 표식, 분홍 방석이 모두 또렷하게 떨어진다. R41의 어둡고 차가운 색과도 겹치지 않는다.

### 엘프식 흔적 (공통 문법)
실루엣을 건드리지 않는 선에서 차량마다 4~6개를 넣었다.
- **작은 엘프가 몰기 위한 개조**: 운전석 분홍 방석(2단, LSV는 등 방석까지), 페달에 OD 끈으로 묶은 나무 연장 블록, 사수 발판(탄약 상자 + 방석), 운전석 문 아래 밧줄 발판(험비), 펜더의 밧줄 사다리(M1A1)
- **모나티엄 창고 태그**: 크림 종이 + 청록 끈, `MNT` + 관리번호(V-0007, V-0012, T-0001, H-0002, C-0001) + 한글 부서명
- **청록 관리번호와 한글 스텐실**: `MNT-V07`(험비), `MNT-V12`(LSV), `MNT-T01`(M1A1), "진압반 수송", "포탑 회전 주의!", "모나티엄 창고"
- **덧칠과 낙서**: 험비 뒤 경고판에 영문 위로 청록 줄을 긋고 "100미터 뒤로!", LSV 스페어 타이어에 노란 '초보운전' 판, M1A1 바구니에 분홍 침낭
- 실존 제조사 로고와 상표는 없다. 각인은 `U.S.`, `CAL .50 M2 HB`, `M240C 7.62 MM`, `STAY BACK 100 M` 같은 일반 표기만 쓴다.

## 2. 거치 무기 규약 (차량 시스템과 맞물리는 부분)

- **요는 `mount_*`, 피치는 무기 루트.** 무기 glb 원점 = 고각 핀(피치축)이고, 피벗 기둥의 수직축(요축)이 이 점을 지난다. 시스템은 `mount_*` 노드에 요를 주고, 그 자식으로 붙인 무기 glb 루트에 로컬 X축 피치를 준다.
- **`mount_*`는 Z축으로 180° 돌려 두었다**(커스텀 속성 `restYawDeg` 180). 무기는 총구 +Y, 차량은 정면 -Y라서다. 무기 glb를 단위 변환으로 자식에 붙이면 바로 앞을 본다. 요를 줄 때는 이 기본 회전을 **보존하고 곱한다**(three.js: `mount.quaternion = rest * yawQuat`). `rotation.y = yaw`로 덮으면 총이 뒤를 본다.
- 부호(three.js): 요 + = 차량 왼쪽(+X)으로, 피치 + = 총구가 위로. 한계는 각 `mount_*`의 `yawMin/yawMax/pitchMin/pitchMax`(도).
- **링 마운트(험비, LSV)**: 사수 링 전체가 `turret`(요 360°)이고 `mount_m2`는 그 자식으로 요 한계 0, 피치만 받는다. 방호판·피벗 기둥·사수 자리(`seat_gunner`)가 링과 함께 돈다.
- **피벗 마운트(M1A1 전차장)**: `mount_m2_cdr`가 직접 요(±180°)를 받는다. 피벗 기둥 메시 `cdr_pintle`이 마운트 자식이라 같이 돈다.
- **공축(M1A1)**: `mount_coax`는 `gun_pitch`의 자식이고 요·피치 한계가 모두 0이다. 주포를 따라간다.
- 피벗 기둥(클레비스 + 기둥)은 차량 쪽이다(`vehicles_us.pintle`). M2 요람 아래 중앙 러그(폭 ±0.025 m)가 클레비스 안에 들어가고 고각 핀이 원점이다.
- `seat_*`의 커스텀 속성 `controls`: 그 자리가 조종하는 노드(쉼표 구분). `drive`, `turret,mount_m2`, `turret,gun_pitch,mount_coax`, `mount_m2_cdr`.

## 5. 차량 시스템 담당을 위한 메모

- **무기 붙이기**: `mount_*`의 `weapon` 속성 = 무기 정의 id = `weapons/us/<id>.glb`. 무기 루트를 마운트의 자식으로 위치·회전 0에 붙인다. 총구·탄피 위치는 무기 glb의 `muzzle`, `eject`, `eject_link`를 쓴다(차량에는 `muzzle_<id>`를 따로 두지 않았다. 주포만 `muzzle_main`).
- **요·피치 적용**: 2장. 요는 `turret` 또는 `mount_*`, 피치는 `gun_pitch` 또는 무기 루트. `mount_*`의 기본 180° 회전을 덮어쓰지 않는다.
- **바퀴**: 원점이 바퀴 중심이고 회전축은 로컬 X. 전진하면 three.js +X 회전이다. 조향은 로컬 Y(three.js)로 주고 회전 순서는 `YXZ`(조향 → 굴림)를 권한다. 오른쪽 바퀴는 대칭 메시라서 같은 부호로 돌리면 된다.
- **궤도**: `track_*`는 정지 메시다. 슈 간격 `pitch`만큼 텍스처 없이 움직임을 내려면 보기륜·유도륜·기동륜을 `radius`에 맞춰 돌리면 충분하다. 궤도 자체를 밀고 싶으면 매 `pitch` 이동마다 메시를 원위치로 되돌리는 방식(슈가 모두 같은 모양)이 가능하다.
- **문·해치**: `rotAxis` + `rotDeg`는 three.js 부모 공간의 전체 열림 각도다. 0 = 닫힘.
- **충돌체**: `COL_*`는 박스 몇 개다. 움직이는 부분의 COL은 해당 노드의 자식이라 같이 돈다. 머티리얼이 투명하지만 엔진에서는 이름으로 숨기고 충돌체만 만든다.
- **좌석 카메라**: `seat_*`는 엘프 눈 위치이고 -Y(three.js +Z)가 정면이다. 사수 자리는 링(포탑)의 자식이라 포탑과 함께 돈다. 험비 `seat_gunner`는 M2 `fpOffset`과 같은 관계(피벗 기준 뒤 0.80, 위 0.33)라서 사수 시점이 fp 모드와 같은 구도다. LSV는 링 반지름 때문에 뒤 0.74, 위 0.33이다.
- **질량·속도 근거**: 험비 M1114 전비 중량 약 5.5 t, 최고 속도 약 100 km/h(27 m/s). LSV는 일반적인 군용 버기의 전투 중량 1.6 t, 120 km/h(33 m/s). M1A1은 57 t, 도로 최고 67 km/h(18.6 m/s). 게임 밸런스에 맞춰 조정해도 된다.
- **장갑(주말농장 법칙)**: 험비·LSV `light`, M1A1 `heavy`. 차량은 파괴 대신 무력화(엔진 정지, 포탑 고장)로 처리한다.

## 6. 검증

- 시트: `npm run shot -- vehicles/us/<id>.glb --views front,34,side,top`
- 엘프 크기 비교와 좌석 시점은 조합 glb로 찍었다(커밋하지 않음, `public/models/_tmp/`는 git이 무시한다). Blender에서 차량 glb를 import하고 `mount_*`에 무기 glb를 단위 변환으로 붙인 뒤, `characters/_kit_elfinia_soldier.glb`를 옆에 세우거나 `seat_*` 위치에 `socket_eye` 빈 오브젝트를 둔다. 그다음 `npm run shot -- _tmp/<조합>.glb --mode fpbody --pitch -8 --hide none`으로 좌석 시점을 찍는다. 열림 확인은 `rotAxis/rotDeg`를 적용해서 찍었다.
- 확인한 것: 문 4개가 바깥으로, 해치가 위로 열린다. 포탑을 돌리면 방호판·피벗·M2·사수 자리가 함께 돈다. 운전석 시점에서 반투명 유리 너머로 후드가 보이고, 엘프 사수 눈높이에서 M2 가늠선이 방호판 창·슬롯과 맞는다.

## 7. 남은 문제
- 운전석 시점의 유리 색(알파 0.26)이 바깥을 약간 푸르게 만든다. 게임에서 시야가 답답하면 `glass` 알파만 낮추면 된다.
- 궤도는 정지 메시라서 슈가 흐르는 표현이 없다(5장 방식 참고).
- M1A1 탑승 연출(`src/game/vehicles/boardingRoutes.ts`)은 승무원 모두 왼쪽 앞 펜더의 밧줄 사다리로 오른다. 포탑이 차체 폭을 거의 다 덮어 옆으로는 오를 데크가 없어서, 탑승 안내 자리를 사다리 쪽 옆면에 늘어놓았다(앞에서부터 조종수 → 탄약수 → 전차장 → 포수). 포탑을 크게 돌려 둔 채 타면 포탑으로 오르는 길이 포탑 모양과 어긋날 수 있다.
- M2 탄통은 길이 방향이 총열과 평행하게 단순화했다(실제 탄 배열과 다를 수 있음).
